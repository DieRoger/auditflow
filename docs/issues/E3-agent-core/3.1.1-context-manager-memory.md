# 3.1.1 — Context Manager + Memory
- **Epic:** E3 Agent Core Runtime
- **Labels:** `agent-kernel`, `runtime`, `memory`
- **Depends on:** 0.5.2.1 (Agent Base + Registry), 0.5.1.1 (Agent Contract)

## Description

实现 Agent 执行期的上下文管理器与会话记忆系统。每个 Agent 在执行链路中需要携带上游 Agent 产出的结构化 Artifact、对话历史以及推理中间状态。Context Manager 负责组装 `AgentRequest.context` 和 `AgentRequest.memory` 字段，确保 Agent 在执行时能获得完整的上下文信息。

核心职责：
- **上下文窗口管理**：根据每个 Agent 的 `max_iterations` 和 LLM context window 限制，自动裁剪/压缩超长上下文
- **记忆持久化**：将 Agent 推理链、Tool 调用历史、中间产出序列化到 Memory Store（PG 表），支持跨 Agent 传递
- **上下文组装策略**：按 Agent 类型差异化 —— Planner 需要完整 Ontology 上下文，Evidence Agent 需要上游 Risk Finding 的 claims_to_verify，Reviewer 需要所有上游 Artifact 摘要

**Agent Flow（上下文流转）：**
```
AgentRequest.context  ←  Workflow Engine 从上游 AgentResponse.result + Artifact 组装
AgentRequest.memory   ←  Memory Store 查询历史推理链（同一 Workflow 内）
    ↓
Agent.execute(request)
    ↓
AgentResponse → Engine 提取 result + memory 写入 Store → 下游 Agent 可读
```

## Acceptance Criteria

- [ ] `ContextManager` 实现：根据 Agent 类型 + token 预算自动分配上下文空间
- [ ] `MemoryStore` 实现：以 `workflow_id` + `agent_name` 为主键的 Append-Only 存储
- [ ] 上下文压缩策略：当累计 token 超过阈值时，自动摘要化早期对话（保留关键 Artifact 引用不压缩）
- [ ] 跨 Agent 传递验证：Planner → Knowledge 能读取 Plan 中的 procedure 列表
- [ ] Memory 写入幂等：同一 `task_id` 重复执行不产生重复记录
- [ ] Memory 与 Hash Chain Audit Log（ADR-004）集成：每次写入自动记录 payload_hash

## I/O Interface

```python
class ContextManager:
    async def build_context(
        self,
        agent_name: str,           # 当前 Agent 名称
        workflow_id: str,
        upstream_artifacts: list[AuditArtifact],  # 上游所有 Artifact
        max_tokens: int = 8000
    ) -> dict: ...                 # AgentRequest.context

    async def compress(
        self,
        context: dict,
        target_tokens: int
    ) -> dict: ...                 # 压缩后的 context

class MemoryStore:
    async def save(
        self,
        workflow_id: str,
        agent_name: str,
        task_id: str,
        reasoning_trace: list[dict],  # Agent 推理步骤
        tool_calls: list[dict]        # Tool 调用记录
    ) -> None: ...

    async def load(
        self,
        workflow_id: str,
        agent_name: str | None = None  # None = 加载全部
    ) -> dict: ...                    # AgentRequest.memory
```

## Evaluation

L2 不直接评估 Context Manager / Memory 本身（其为基础设施组件），通过以下间接指标验证：

| 间接指标 | 测量方式 |
|---------|---------|
| 上下文完整性 | Planner→Knowledge→Risk→Evidence→Reviewer 全链路无丢失 Artifact 引用 |
| Memory 准确性 | 同一 Workflow 内 Agent 能正确回溯上游推理链（Regression Test） |
| 压缩保真度 | 压缩后 Agent 关键决策不变（与未压缩 Baseline 对比） |
