# 3.2.1 — Planner Agent
- **Epic:** E3 Agent Core Runtime
- **Labels:** `agent`, `planner`, `core`
- **Depends on:** 3.1.2 (Checkpoint + Replay), 1B.1.1 (Ontology Schema)

## Description

实现 Planner Agent —— 5-Agent 审计链的起点。Planner 接收审计目标（从用户输入 + 文档元数据提取），查询 E1B 构建的 Ontology Reasoning Chains，将高层审计目标拆解为结构化的子任务序列，并指定每个子任务所需的 Agent 类型和预期证据类型。

**Agent Flow：**
```
审计目标（项目描述 + 财务报表摘要）
    ↓
1. 查询 Ontology Reasoning Chains → 匹配审计领域
    ↓   (ontology_query tool)
2. 识别关键 Assertion → Procedure → Evidence 链路
    ↓
3. 拆解子任务：
    ├── 收入确认审计 → Knowledge Agent（检索 IFRS 15 + ISA 240）
    ├── 应收账款审计 → Evidence Agent（查询客户文档）
    ├── 风险评估 → Risk Agent（综合 Knowledge + Evidence）
    └── ...
    ↓
4. 生成 Agent 序列 → 输出 AuditPlanArtifact
```

**产出 Artifact:** `AuditPlanArtifact`（含 `materiality`、`sampling_strategy`、`procedures`、`timeline`）

**Tools:** `ontology_query`（查询 Ontology 节点和推理链）、`agent_catalog`（列出可用 Agent 及其能力）

## Acceptance Criteria

- [ ] 给定审计目标 → 自动匹配 ≥1 条 Ontology Reasoning Chain
- [ ] 产出 `AuditPlanArtifact` 含完整 `procedures` 列表（每个 procedure 有 type、steps、evidence_required）
- [ ] 子任务序列覆盖所有匹配的审计领域（无遗漏）
- [ ] 每个子任务指定 target_agent（Knowledge/Risk/Evidence/Reviewer）
- [ ] 所有推理步骤有 Ontology 节点引用（可追溯到 `ontology_node.id`）
- [ ] 未匹配到任何 Reasoning Chain → AgentResponse.status="PARTIAL" + next_action="HUMAN_REVIEW"

## I/O Interface

```python
# AgentRequest.inputs
{
    "project_description": str,           # 审计项目描述
    "financial_summary": dict,            # 财务报表关键数据
    "document_ids": list[str],            # 已上传文档 ID
    "audit_scope": str                    # 审计范围（如 "FY2025 Annual Audit"）
}

# AgentResponse.result → AuditPlanArtifact.content
class AuditPlanContent(BaseModel):
    materiality: MaterialityCalc
    sampling_strategy: SamplingStrategy
    procedures: list[ProcedureDef]
    timeline: dict

class ProcedureDef(BaseModel):
    procedure_id: str
    type: str                            # Inspection | Confirmation | Analytical | Inquiry | Recalculation
    area: str                            # 审计领域（如 Revenue Recognition）
    assertions: list[str]                # Existence | Accuracy | Cutoff | ...
    steps: list[str]                     # 具体步骤描述
    evidence_required: list[str]         # 所需证据类型
    target_agent: str                    # Knowledge | Risk | Evidence
    ontology_chain_ref: str              # 引用的 Ontology 推理链 ID

class MaterialityCalc(BaseModel):
    base_amount: float
    percentage: float
    materiality_threshold: float
    performance_materiality: float

class SamplingStrategy(BaseModel):
    method: str                          # MUS | Random | Stratified
    sample_size: int
    selection_criteria: str
```

## Evaluation

| L2 指标 | 说明 | 计算方式 | 目标 |
|---------|------|---------|------|
| **Plan Completeness** | 计划完整性 | Planner 产出的子任务覆盖 Benchmark 标注的关键审计领域 | ≥ 0.80 |
| **Ontology Alignment** | 本体对齐度 | Planner 选择的 Reasoning Chain 与标注链条的匹配程度 | ≥ 0.75 |
