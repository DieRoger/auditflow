# 3.2.2 — Knowledge Agent
- **Epic:** E3 Agent Core Runtime
- **Labels:** `agent`, `knowledge`
- **Depends on:** 2.1.2 (Hybrid Merge + Reranker), 1B.2.2 (Knowledge Embedding → PGVector)

## Description

实现 Knowledge Agent —— 负责检索审计准则（ISA 315/330/500/240 + IFRS 15）并返回原文 + LLM 解读。Knowledge Agent 是审计专业性的第一道保障：它不依赖 LLM 的零样本审计知识，而是从已入库的审计准则原文中检索相关条款，再由 LLM 将其与当前审计上下文结合解读。

**Agent Flow：**
```
接收 AuditPlanArtifact 中的 procedures（或直接 query）
    ↓
1. 解析查询意图 → 提取审计领域 + 关键词
    ↓   (standard_search tool → Hybrid Search over PGVector source_type=AUDIT_STANDARD)
2. 检索 Top-K 审计准则条款
    ↓   (cross_reference tool)
3. 交叉引用：该条款引用了哪些其他条款？哪些条款引用它？
    ↓
4. LLM 解读：每条准则在当前审计上下文中的含义和适用性
    ↓
5. 输出 KnowledgePackageArtifact
```

**产出 Artifact:** `KnowledgePackageArtifact`（含 `standards` + `interpretations` + `citations`）

**Tools:** `standard_search`（Hybrid Search 审计准则）、`cross_reference`（准则间交叉引用查询）

## Acceptance Criteria

- [ ] 给定审计领域查询 → 返回 Top-5 相关 ISA/IFRS 条款（含原文摘录）
- [ ] 每条结果含：条款编号、原文摘录（≤300 tokens）、LLM 解读（≤200 tokens）、Citation
- [ ] 交叉引用完整：每条条款列出 `references`（引用其他条款）和 `referenced_by`（被其他条款引用）
- [ ] 无相关准则 → AgentResponse.status="PARTIAL" + 明确说明覆盖缺口
- [ ] 解读质量：LLM 解读不歪曲原文含义（人工抽查 ≥95% 准确率）

## I/O Interface

```python
# AgentRequest.inputs
{
    "queries": list[str],                # 审计领域查询列表（来自 Planner procedures）
    "audit_areas": list[str],            # 审计领域
    "standards_filter": list[str] | None # 限定准则范围（如 ["ISA 315", "IFRS 15"]）
}

# AgentResponse.result → KnowledgePackageArtifact.content
class KnowledgePackageContent(BaseModel):
    items: list[KnowledgeItem]

class KnowledgeItem(BaseModel):
    query: str                           # 原始查询
    standard_id: str                     # 准则编号（如 "ISA 240 ¶32"）
    standard_title: str                  # 准则全称
    excerpt: str                         # 原文摘录
    interpretation: str                  # LLM 在审计上下文中的解读
    relevance_score: float               # 相关度分数
    references: list[str]                # 该条款引用的其他条款
    referenced_by: list[str]             # 引用该条款的其他条款
    citation: Citation                   # 完整 Citation（含 source + chunk_id）
```

## Evaluation

| L2 指标 | 说明 | 计算方式 | 目标 |
|---------|------|---------|------|
| **Standard Retrieval Precision@5** | Top-5 准则检索精确率 | 相关条款数 / 5 | ≥ 0.80 |
| **Citation Accuracy** | 引用准确率 | LLM 解读中引用的条款编号与实际条款内容一致 | ≥ 0.90 |
