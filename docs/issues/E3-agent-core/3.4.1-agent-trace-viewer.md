# 3.4.1 — Agent Trace Viewer + Workflow Monitor
- **Epic:** E3 Agent Core Runtime
- **Labels:** `frontend`, `monitor`, `websocket`
- **Depends on:** 3.1.3 (Agent Execution API), 0.5.1.3 (Event Contract)

## Description

实现 Agent Trace Viewer 和 Workflow Monitor 前端页面。这是 E3 阶段的用户可见产出 —— 让审计师能够实时观察 5-Agent 审计链的执行过程，追踪每个 Agent 的推理步骤、Tool 调用、中间产出和最终决策。

**Agent Trace Viewer：**
- 以 React Flow DAG 图形式展示 Workflow 中 Agent 的执行拓扑
- 每个 Agent 节点可展开：查看推理链（AgentThinking）、Tool 调用历史（ToolCalled/ToolCompleted）、中间 Artifact
- 支持时间线回放：拖动时间轴查看每一步的执行快照

**Workflow Monitor：**
- 实时 WebSocket 推送（16 种 Event 类型全部订阅）
- 展示当前 Workflow 状态（CREATED → RUNNING → WAITING_APPROVAL → COMPLETED / FAILED）
- 待审批队列：HIGH/CRITICAL 风险自动高亮 + 一键跳转审批页面（E4 实现）
- 执行统计：总耗时、Token 消耗、成本估算

**技术要点：**
- **Backend Capability First 原则：** 前端只消费 E3 已冻结的 `POST /internal/agents/{name}/execute` 和 `WS /api/v1/ws/workflows/{id}`
- 前端可基于 E0.5 冻结的 Event Contract 用 MSW Mock 开发
- WebSocket 连接管理：自动重连 + 断线期间事件回放

## Acceptance Criteria

- [ ] React Flow DAG 正确渲染 5-Agent 拓扑（含并行 Knowledge + Evidence 分支）
- [ ] 每个 Agent 节点状态实时更新（pending / running / completed / failed / waiting_approval）
- [ ] 点击 Agent 节点 → 展开推理链面板（AgentThinking 事件列表 + Tool 调用时间线）
- [ ] WebSocket 实时接收 16 种 Event → UI 即时更新
- [ ] Workflow Monitor 首页展示：当前活跃 Workflow 列表 + 执行时长 + Agent 状态概要
- [ ] 断线自动重连 + 事件回放（≤5 秒补齐断线期间事件）
- [ ] 响应式布局（Desktop 优先，Tablet 基本可用）
- [ ] 暗色模式支持

## I/O Interface

```typescript
// WebSocket 订阅
const ws = new WebSocket(`ws://localhost:8000/api/v1/ws/workflows/${workflowId}`);

// 接收事件类型（16 种，见 ADR-001 Event Contract）
type WorkflowEvent = {
    event_id: string;
    workflow_id: string;
    event_type: EventType;
    timestamp: string;
    payload: Record<string, unknown>;
};

// React Flow Node 数据结构
interface AgentNode {
    id: string;
    type: 'agent';
    data: {
        agentName: string;
        status: 'pending' | 'running' | 'completed' | 'failed' | 'waiting_approval';
        artifactIds: string[];
        durationMs: number | null;
        tokenCount: number | null;
        iterationCount: number;
        events: WorkflowEvent[];        // 该 Agent 的所有事件
    };
    position: { x: number; y: number };
}

// Trace 时间线条目
interface TraceEntry {
    timestamp: string;
    agentName: string;
    eventType: EventType;
    summary: string;                    // 人类可读的摘要
    detail: Record<string, unknown>;    // 原始 payload
}
```

## Evaluation

L2 不直接评估（前端页面），通过以下 QA 标准验证：

| QA 标准 | 验证方式 |
|---------|---------|
| WebSocket 延迟 | Event 从后端发布到前端渲染 < 500ms |
| DAG 拓扑正确性 | 并行 Knowledge + Evidence 分支在视觉上明确区分 |
| 事件完整性 | 16 种 Event 类型全部有对应 UI 渲染（无静默丢弃） |
| 断线恢复 | 模拟断线 5s → 重连后事件无缺失 |
