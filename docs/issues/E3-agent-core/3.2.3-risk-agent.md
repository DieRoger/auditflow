# 3.2.3 — Risk Agent
- **Epic:** E3 Agent Core Runtime
- **Labels:** `agent`, `risk`, `core`
- **Depends on:** 3.1.2 (Checkpoint + Replay), 1B.1.1 (Ontology Schema)

## Description

实现 Risk Agent —— **AuditFlow 的核心价值 Agent**。Risk Agent 接收 Evidence Package + Knowledge Package，查询 Ontology 推理链匹配 Risk Indicators，进行风险评估（Severity + Probability），并在证据不足时主动请求 Evidence Agent 补充证据，形成迭代循环。HIGH/CRITICAL 风险强制触发 HUMAN_REVIEW。

**Agent Flow（含迭代循环）：**
```
1. 接收 EvidencePackageArtifact + KnowledgePackageArtifact
    ↓
2. 查询 Ontology 推理链 → 匹配 Risk Indicators
    ↓   (ontology_query tool)
3. 评估 Severity + Probability
    ↓   (calculator tool → Materiality 量化计算)
4. 证据不足？
    ├── YES → 请求 Evidence Agent 补充 → next_action="EVIDENCE_AGENT"
    │         ↓ 等待 Evidence 返回新 EvidencePackageArtifact
    │         ↓ 返回 step 2（iteration++）
    └── NO  → 证据充分
    ↓
5. 推荐审计程序 → 输出 RiskFindingArtifact
    ↓
6. HIGH/CRITICAL？→ 强制 next_action="HUMAN_REVIEW"
```

**Runtime Limits（Risk Agent 特定）：**
- `max_iterations: 3` — Evidence 不足时最多 3 次补充检索
- 3 次仍无法判断 → `WAITING_APPROVAL`（人工介入）
- `require_human_after_failure: true`

**产出 Artifact:** `RiskFindingArtifact`（含 `area` / `severity` / `probability` / `indicators` / `suggested_procedures` / `reasoning`）

**Tools:** `evidence_search`（查询已有 Evidence Package）、`standard_search`（验证风险是否对应准则要求）、`calculator`（Materiality 量化计算）、`ontology_query`

## Acceptance Criteria

- [ ] 自动匹配 Ontology 推理链：Risk Area → Assertion → Indicators
- [ ] 证据不足时主动请求补充（`next_action="EVIDENCE_AGENT"`，含明确 `claims_to_verify`）
- [ ] HIGH / CRITICAL → 强制 `next_action="HUMAN_REVIEW"`（不可跳过）
- [ ] 所有 Indicators 有 Citation（指向 Evidence 或 Knowledge 源）
- [ ] `reasoning` 字段包含完整推理链（Risk → Indicator → Evidence → Severity → Procedure）
- [ ] 3 次迭代后仍无法判断 → `status="NEEDS_HUMAN"` + `next_action="HUMAN_REVIEW"`
- [ ] 每次迭代自动写入 Audit Log（Hash Chain）

## I/O Interface

```python
# AgentRequest.inputs
{
    "evidence_package_id": str,          # 上游 EvidencePackageArtifact
    "knowledge_package_id": str,         # 上游 KnowledgePackageArtifact
    "audit_plan_id": str,                # 上游 AuditPlanArtifact（含审计范围和 Materiality）
    "context": dict                      # 从 Planner 传递的审计目标上下文
}

# AgentResponse.result → RiskFindingArtifact.content
class RiskFindingContent(BaseModel):
    area: str                            # 审计领域（Revenue Recognition / AR Impairment / ...）
    title: str                           # 风险标题（如 "激进收入确认风险"）
    severity: Literal["CRITICAL", "HIGH", "MEDIUM", "LOW"]
    probability: float                   # 0–1
    indicators: list[RiskIndicator]
    related_standards: list[str]         # 关联审计准则
    suggested_procedures: list[ProcedureSuggestion]
    reasoning: list[str]                 # Agent 推理链（每步可追溯）

class RiskIndicator(BaseModel):
    indicator: str                       # 如 "收入增长率 45%，行业均值 10%"
    source: str                          # 数据来源（Evidence / Knowledge / Ontology）
    citation: Citation                   # 指向源数据的 Citation
    weight: float                        # 该 Indicator 对 Severity 的贡献权重

class ProcedureSuggestion(BaseModel):
    procedure_type: str                  # Inspection | Confirmation | Analytical | Inquiry | Recalculation
    description: str                     # 程序描述
    ontology_chain_ref: str              # 引用的 Ontology 推理链
```

## Evaluation

| L2 指标 | 说明 | 计算方式 | 目标 |
|---------|------|---------|------|
| **Risk Classification Accuracy** | 风险分类准确率 | 正确识别的风险领域数 / 标注风险总数 | ≥ 0.85 |
| **Severity Accuracy** | 严重程度准确率 | 严重程度正确的风险数 / 标注风险总数 | ≥ 0.75 |
| **Reasoning Quality** | 推理质量 | LLM-as-Judge 评估 + 人工抽查（1–5 Likert） | ≥ 3.5 |
