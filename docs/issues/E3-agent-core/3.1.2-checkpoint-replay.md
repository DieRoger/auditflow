# 3.1.2 — Checkpoint + Replay 生产化
- **Epic:** E3 Agent Core Runtime
- **Labels:** `agent-kernel`, `runtime`, `checkpoint`, `replay`
- **Depends on:** 0.5.2.3 (Execution Trace + Checkpoint), 3.1.1 (Context Manager + Memory)

## Description

将 E0.5 原型阶段的 Execution Trace + Checkpoint 机制生产化。Checkpoint 确保长时间运行的 5-Agent 审计工作流在任意节点故障后可恢复，无需从头重跑。Replay 引擎支持基于已保存的 Trace 完整复现一次 Workflow 执行，用于调试、Regression Test 和 Audit Log 审计复核。

核心职责：
- **Checkpoint 自动保存**：每个 Agent 执行完成（含 AGENT_COMPLETED / AGENT_FAILED / WAITING_APPROVAL 事件）自动写入 Checkpoint
- **恢复策略**：Workflow 重启时检测最近 Checkpoint，从中断点继续执行（跳过已完成的 Agent）
- **Replay 引擎**：给定 `workflow_id`，从 Execution Trace 中回放所有 Agent 的输入/输出，验证确定性
- **Runtime Limits 集成**：Checkpoint 记录当前 `iteration` 计数和 `timeout` 剩余时间，恢复后继续累加

**Agent Flow（Checkpoint 生命周期）：**
```
Workflow START
    ↓
Agent A 执行 → AGENT_COMPLETED → Checkpoint #1 (agent=A, status=done, artifacts=[...])
    ↓
Agent B 执行 → AGENT_COMPLETED → Checkpoint #2 (agent=B, status=done, artifacts=[...])
    ↓
Agent C 执行 → CRASH
    ↓
Workflow RESTART → 加载 Checkpoint #2 → Agent C 重新执行
    ↓
Agent C → AGENT_COMPLETED → Checkpoint #3 → 继续下游...
```

## Acceptance Criteria

- [ ] 每个 Agent 完成/失败/暂停事件自动触发 Checkpoint 写入（不可配置关闭）
- [ ] Checkpoint 包含：`workflow_id`、`completed_agents`、`current_agent`、`artifacts_produced`、`iteration_count`、`elapsed_time_ms`
- [ ] 故障恢复测试：模拟 Agent C 崩溃 → Workflow 重启 → 从 Agent C 继续（不重跑 A/B）
- [ ] Replay 引擎可复现：给定 `workflow_id` → 回放全部 Agent 调用链 → 输出与原始一致的 Artifact 序列
- [ ] Runtime Limits 恢复后正确累加：Agent C 崩溃前已用 2 次 iteration，恢复后从 iteration=2 继续（而非重置为 0）
- [ ] Checkpoint 与 Append-Only Audit Log 集成（见 ADR-004）

## I/O Interface

```python
class CheckpointManager:
    async def save(
        self,
        workflow_id: str,
        checkpoint: WorkflowCheckpoint
    ) -> None: ...

    async def load_latest(
        self,
        workflow_id: str
    ) -> WorkflowCheckpoint | None: ...

    async def list_checkpoints(
        self,
        workflow_id: str
    ) -> list[WorkflowCheckpoint]: ...

class WorkflowCheckpoint(BaseModel):
    workflow_id: str
    sequence: int                     # 自增序号（#1, #2, #3...）
    completed_agents: list[str]       # 已完成的 Agent 名称列表
    current_agent: str | None         # 当前正在执行的 Agent（AGENT_STARTED 后写入）
    artifacts_produced: list[str]     # 已产出的 artifact_id 列表
    iteration_count: int              # 当前 Agent 已用迭代次数
    elapsed_time_ms: int              # 已用时间
    memory_snapshot: dict             # 当前 Memory Store 快照引用
    created_at: datetime

class ReplayEngine:
    async def replay(
        self,
        workflow_id: str,
        validate_determinism: bool = True
    ) -> ReplayReport: ...

class ReplayReport(BaseModel):
    workflow_id: str
    original_artifacts: list[str]
    replayed_artifacts: list[str]
    match: bool                       # 是否完全一致
    diffs: list[dict]                 # 不一致详情
```

## Evaluation

L2 不直接评估（基础设施组件），通过以下间接指标验证：

| 间接指标 | 测量方式 |
|---------|---------|
| 恢复成功率 | 模拟 100 次随机崩溃 → 恢复成功率 ≥ 99% |
| Replay 一致性 | 100 次 Replay → Artifact 完全一致率 ≥ 95%（允许 LLM 非确定性差异） |
| 恢复延迟 | Checkpoint 加载 + 继续执行 < 5s 额外开销 |
