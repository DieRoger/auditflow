# 3.1.3 — Agent Execution API
- **Epic:** E3 Agent Core Runtime
- **Labels:** `agent-kernel`, `runtime`, `api`
- **Depends on:** 0.5.2.2 (Workflow Engine + HITL 状态机), 3.1.1 (Context Manager + Memory)

## Description

实现统一的 Agent Execution API：`POST /internal/agents/{name}/execute`。这是 Workflow Engine 调度 5 个 Agent 的唯一入口，封装了 Agent 执行的全部生命周期 —— 前置 Context 组装、Runtime Limits 校验、Tool 调用拦截、执行后 Artifact 持久化、Event 发布。

**API Freeze: Agent Execution API v1**（E3 完成时冻结）。

核心职责：
- **统一调度入口**：Workflow Engine 不直接调用 `agent.execute()`，全部通过此 API 路由
- **Runtime Limits 强制执行**：读入 `agent_runtime_limits.yaml` 配置，超时/超迭代自动中断
- **Event 自动发布**：AgentStarted → ToolCalled → ToolCompleted → AgentCompleted → AgentFailed（按实际执行自动触发）
- **Artifact 自动持久化**：AgentResponse 中的 result 自动转为已注册 Artifact 类型并写入存储
- **HITL 触发**：Agent 返回 `NEEDS_HUMAN` 或 HIGH/CRITICAL 风险 → 自动转入 WAITING_APPROVAL

**Agent Flow：**
```
POST /internal/agents/{name}/execute
    │
    ├── 1. 校验 agent_name ∈ Registry
    ├── 2. 加载 Runtime Limits (max_iterations, timeout, retry_policy)
    ├── 3. ContextManager.build_context(...)
    ├── 4. 发布 AGENT_STARTED Event
    │
    ├── 5. Loop (iteration ≤ max_iterations):
    │       ├── agent.execute(request)
    │       ├── 拦截 Tool 调用 → 发布 TOOL_CALLED / TOOL_COMPLETED
    │       ├── 检查 timeout → 超时则 AGENT_FAILED
    │       └── 检查 next_action:
    │             ├── "EVIDENCE_AGENT" → iteration++ → 继续循环
    │             ├── "HUMAN_REVIEW" → 发布 APPROVAL_REQUIRED → 返回 NEEDS_HUMAN
    │             └── "COMPLETE" → 退出循环
    │
    ├── 6. Artifact 持久化（ArtifactRegistry 校验类型）
    ├── 7. 发布 AGENT_COMPLETED / AGENT_FAILED / APPROVAL_REQUIRED
    └── 8. 返回 AgentResponse
```

## Acceptance Criteria

- [ ] `POST /internal/agents/{name}/execute` 接收 `AgentRequest`，返回 `AgentResponse`
- [ ] 未注册 Agent 名称 → 400 + 错误详情
- [ ] Runtime Limits 生效：超时 → 自动 AGENT_FAILED；超迭代 → 自动中断 + WAITING_APPROVAL
- [ ] 所有 Event 自动发布（AgentStarted/AgentThinking/ToolCalled/ToolCompleted/AgentCompleted/AgentFailed/ApprovalRequired）并持久化到 Audit Log
- [ ] Artifact 输出自动通过 ArtifactRegistry 校验，未注册类型拒绝写入
- [ ] 重试策略：retry_on 错误自动重试（max 3 次，exponential backoff）
- [ ] API 响应 < 200ms（不含 Agent 实际执行时间）

## I/O Interface

```python
# POST /internal/agents/{name}/execute
# Request Body: AgentRequest
# Response Body: AgentResponse

class AgentExecutionConfig(BaseModel):
    agent_name: str
    max_iterations: int = 3
    timeout_seconds: int = 300
    retry_policy: RetryPolicy
    human_escalation: HumanEscalationConfig

class RetryPolicy(BaseModel):
    max_retries: int = 3
    backoff: Literal["exponential", "linear"] = "exponential"
    retry_on: list[str] = ["LLM_TIMEOUT", "API_ERROR", "NETWORK_ERROR"]

class HumanEscalationConfig(BaseModel):
    after_failed_retries: bool = True
    on_high_risk: bool = True
```

## Evaluation

L2 不直接评估（基础设施组件），通过以下 CI 验证：

| 验证项 | 测量方式 |
|-------|---------|
| API Contract 合规 | 所有 5 个 Agent 通过此 API 执行 → 返回 Schema 符合 AgentResponse |
| Runtime Limits 生效 | 注入超时场景 → AGENT_FAILED 在 timeout_seconds 内触发 |
| Event 完整性 | 单次 Agent 执行 → ≥4 个 Event（Started + ≥1 Tool + Completed） |
