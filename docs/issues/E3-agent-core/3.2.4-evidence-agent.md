# 3.2.4 — Evidence Agent
- **Epic:** E3 Agent Core Runtime
- **Labels:** `agent`, `evidence`
- **Depends on:** 2.2.1 (Evidence Collector + Citation Builder)

## Description

实现 Evidence Agent —— 负责从客户文档中检索、验证、封装审计证据。Evidence Agent 接收来自 Risk Agent（或 Planner）的 `claims_to_verify`，通过 Hybrid Search 在客户文档中查找支撑或反驳每项声明的证据，最终封装为 `EvidencePackageArtifact`。

**Agent Flow：**
```
接收 claims_to_verify（来自 Risk Agent 或 Planner）
    ↓
1. 逐 Claim 执行 Hybrid Search
    ↓   (client_document_search tool → PGVector source_type=CLIENT_DOCUMENT)
2. 候选 Chunk 筛选：相关性 ≥ threshold → 保留
    ↓
3. 对每个保留 Chunk：提取关键数据 → Citation 封装
    ↓   (structured_data_query tool → 结构化查询财务报表数值)
4. 评估 Coverage：有证据的 claim / 总 claim
    ↓
5. 输出 EvidencePackageArtifact
    ├── 如果 coverage < threshold → next_action="RISK_AGENT"（请求 Risk 进一步判断）
    └── 如果 coverage ≥ threshold → next_action="COMPLETE"
```

**产出 Artifact:** `EvidencePackageArtifact`（含 `claims` + `sources` + `coverage` + `unmatched`）

**Tools:** `client_document_search`（Hybrid Search 客户文档）、`structured_data_query`（结构化查询财务报表数值）

## Acceptance Criteria

- [ ] 接收 `claims_to_verify` 列表 → 逐 Claim 返回 ≥1 条证据或标记为 unmatched
- [ ] 每条证据含完整 Citation（document_id / chunk_id / excerpt / relevance_score）
- [ ] Coverage 计算准确：`matched_claims / total_claims`
- [ ] Coverage < 70% → 自动标记 `next_action="RISK_AGENT"`（触发 Risk 迭代循环）
- [ ] 支持按证据类型过滤（sales_contracts / shipping_docs / customer_confirmations / financial_statements）
- [ ] 结构化数据查询：能从财务报表表格中提取具体数值（如 revenue、receivable_days）

## I/O Interface

```python
# AgentRequest.inputs
{
    "claims_to_verify": list[str],       # 待验证声明列表
    "evidence_types": list[str] | None,  # 限定证据类型（如 ["sales_contracts", "shipping_docs"]）
    "document_ids": list[str] | None,    # 限定文档范围
    "relevance_threshold": float = 0.6   # 相关度阈值
}

# AgentResponse.result → EvidencePackageArtifact.content
class EvidencePackageContent(BaseModel):
    claims: list[EvidencedClaim]
    coverage: float                      # matched / total
    unmatched: list[str]                 # 未匹配的 claim 文本

class EvidencedClaim(BaseModel):
    claim: str                           # 原始声明
    status: Literal["SUPPORTED", "REFUTED", "INCONCLUSIVE"]
    evidence_items: list[EvidenceItem]
    overall_assessment: str              # 对该 claim 的综合评估

class EvidenceItem(BaseModel):
    document_id: str
    chunk_id: str
    excerpt: str                         # 文档原文摘录
    relevance_score: float
    data_point: dict | None              # 结构化数据提取（如 {"revenue": "1.2B", "revenue_growth": "45%"}）
    citation: Citation                   # 完整 Citation
```

## Evaluation

| L2 指标 | 说明 | 计算方式 | 目标 |
|---------|------|---------|------|
| **Evidence Coverage** | 证据覆盖度 | 已收集证据类型数 / 标注证据类型数 | ≥ 0.70 |
| **Citation Source Accuracy** | 引用来源准确率 | Citation 指向的文档位置与实际内容一致 | ≥ 0.90 |
