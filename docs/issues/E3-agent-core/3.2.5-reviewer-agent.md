# 3.2.5 — Reviewer Agent
- **Epic:** E3 Agent Core Runtime
- **Labels:** `agent`, `reviewer`
- **Depends on:** 3.1.2 (Checkpoint + Replay), 2.2.2 (Grounding Checker)

## Description

实现 Reviewer Agent —— **审计质量的最后一道 AI 防线**。Reviewer 审查上游所有 Agent 产出的 Artifact（Plan → Knowledge → Risk → Evidence），检测遗漏、幻觉、弱逻辑等问题，最终决定 APPROVED / NEEDS_REVISION / REJECTED。`quality_score` 低于阈值自动退回上游 Agent 重新执行。

**Agent Flow：**
```
接收上游所有 Artifact（AuditPlan + KnowledgePackage + RiskFinding + EvidencePackage）
    ↓
1. 逐 Artifact 审查：
    ├── 检测 ≥3 类问题：
    │     ├── 无引用（Claim 无 Citation）
    │     ├── 弱逻辑（推理链不完整或跳跃）
    │     ├── 幻觉（引用的准则条款不存在或内容不匹配）
    │     └── 证据不足（Risk 结论与 Evidence Coverage 矛盾）
    │   (evidence_search + standard_search + grounding_checker tools)
    ↓
2. 计算 quality_score（加权综合）
    ↓
3. 判断：
    ├── quality_score ≥ 0.85 → APPROVED → 工作流继续
    ├── 0.60 ≤ quality_score < 0.85 → NEEDS_REVISION → 退回指定 Agent + 附带 issues
    └── quality_score < 0.60 → REJECTED → 退回 Planner 重新规划
    ↓
4. 输出 ReviewReportArtifact
```

**产出 Artifact:** `ReviewReportArtifact`（含 `review_result` + `issues` + `quality_score`）

**Tools:** `evidence_search`（交叉验证 Evidence）、`standard_search`（验证准则引用正确性）、`grounding_checker`（E2 就绪的 L3 Grounding Checker）

## Acceptance Criteria

- [ ] 检测 ≥3 类问题：无引用（missing_citation）、弱逻辑（weak_reasoning）、幻觉（hallucination）、证据不足（insufficient_evidence）
- [ ] `quality_score < 0.85` → 自动退回上游 Agent（`next_action` 指向具体 Agent 名称）
- [ ] `quality_score < 0.60` → 退回 Planner 重新规划（`next_action="PLANNER_AGENT"`）
- [ ] 每条 Issue 含：问题类型、严重程度、问题描述、指向的 Artifact + 字段路径
- [ ] Grounding Checker（L3 Evaluation）集成：自动标记 Unsupported Claim
- [ ] Reviewer 自身不引入幻觉：Reviewer 引用的准则条款必须可检索验证

## I/O Interface

```python
# AgentRequest.inputs
{
    "artifacts": list[str],              # 上游所有 artifact_id
    "artifact_types": list[str],         # 对应的 artifact_type
    "audit_plan_id": str                 # 顶层 AuditPlan（用于全局一致性校验）
}

# AgentResponse.result → ReviewReportArtifact.content
class ReviewReportContent(BaseModel):
    review_result: Literal["APPROVED", "NEEDS_REVISION", "REJECTED"]
    issues: list[ReviewIssue]
    quality_score: float                 # 0–1
    summary: str                         # 审查摘要

class ReviewIssue(BaseModel):
    issue_id: str
    issue_type: Literal[
        "missing_citation",              # 声明无引用来源
        "weak_reasoning",                # 推理链不完整或跳跃
        "hallucination",                 # 引用准则不存在或内容不匹配
        "insufficient_evidence",         # 结论与证据覆盖度矛盾
        "contradiction",                 # 不同 Artifact 间矛盾
        "scope_gap"                      # 遗漏审计领域
    ]
    severity: Literal["CRITICAL", "HIGH", "MEDIUM", "LOW"]
    description: str
    artifact_id: str                     # 指向的问题 Artifact
    field_path: str                      # 问题字段路径（如 "RiskFindingContent.reasoning[2]"）
    suggestion: str                      # 修复建议
```

## Evaluation

| L2 指标 | 说明 | 计算方式 | 目标 |
|---------|------|---------|------|
| **Issue Detection Rate** | 问题检出率 | 检出的已知错误数 / Benchmark 预设错误总数 | ≥ 0.80 |
| **False Positive Rate** | 误报率 | 错误标记为问题的次数 / 总标记数 | ≤ 0.15 |

**已知错误注入：** Benchmark 的某些 Case 预设了"已知错误"——例如 Risk Agent 被注入一个故意错误的 severity 判定、或 Knowledge Agent 引用了一个不存在的条款编号。Reviewer 的 Issue Detection Rate 衡量其发现这些注入错误的能力。
