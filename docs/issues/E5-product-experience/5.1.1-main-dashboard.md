# 5.1.1 — Main Dashboard（主仪表盘）
- **Epic:** E5 Product Experience
- **Labels:** `frontend`, `dashboard`, `kpi`, `websocket`, `react`
- **Depends on:** E1A (Document API v1), E1B (Knowledge API v1), E2 (Search API v1 / Evidence API v1), E3 (Agent Execution API v1 + WebSocket 事件), E4 (Approval API v1 / Report API v1)

## Description

实现 Main Dashboard —— AuditFlow 的首页仪表盘，审计师登录后看到的第一个页面。聚合展示当前审计项目的关键 KPI、最近活动时间线、待审批事项概览，以及快速入口。数据通过各 Epic 已冻结的 REST API 获取，并通过 WebSocket 接收实时事件更新。

**核心交互：**
1. 页面加载时聚合调用多个已冻结 API（聚合层或前端并行请求）
2. WebSocket 监听全局 Workflow 事件（`AgentCompleted`、`RiskDetected`、`ApprovalRequired` 等）实时更新 KPI 和时间线
3. 点击时间线条目 → 跳转到对应详情页（Agent Trace / 风险页 / 审批页）
4. 待审批小部件点击 → 跳转到 Approval Management Page（4.2.1）
5. 快捷操作卡片提供新建项目、上传文档入口

**前端技术约束（Backend Capability First）：**
- 仅消费已冻结的 API v1（E1A–E4 各阶段冻结后逐一接入）
- KPI 聚合推荐后端提供 `/api/v1/dashboard/summary` 聚合端点（减少前端 N+1 请求），但 MVP 阶段前端可并行调用各独立端点
- 使用 MSW Mock 开发，等待各 Epic API 就绪
- 不使用尚未冻结的后端 Schema

## Acceptance Criteria

- [ ] **KPI 卡片区（4 张卡片）：** 活跃项目数、本周完成 Workflow 数、风险发现总数（按严重程度细分）、待审批事项数（红色角标 HIGH 数量）。每张卡片含环比变化趋势箭头。
- [ ] **KPI 数据来源：** `GET /api/v1/projects`（项目数）、`GET /api/v1/workflows?status=completed&since={week_start}`（完成数）、`GET /api/v1/artifacts?artifact_type=risk_finding`（风险数）、`GET /api/v1/approvals?status=pending`（待审批数）。前端并行请求，任一失败不影响其余卡片（独立 Error 状态）。
- [ ] **最近活动时间线：** 展示最近 20 条 Workflow 事件（`AgentCompleted`、`RiskDetected`、`ArtifactCreated`、`WorkflowCompleted`、`ApprovalSubmitted`），每条含时间戳、Agent/组件名称、摘要。WebSocket 实时追加新事件到顶部。
- [ ] **待审批小部件：** 展示最近 5 条 `status=pending` 的审批项。点击跳转到 Approval Management Page。WebSocket `ApprovalRequired` 事件实时追加。
- [ ] **项目进度概览：** 展示最近 5 个项目的进度条（基于 Workflow 完成率）、状态标签（待开始/审计中/待审批/已完成）。
- [ ] **快捷操作：** "新建项目" → Project Management Page（5.1.2）；"上传文档" → Document Center（E1A 页面）；"快速检索" → Evidence Browser（E2 页面）。
- [ ] **KPI 自动刷新：** 每 60 秒轮询刷新 KPI 数据；WebSocket 事件触发即时增量更新。
- [ ] **Backend Capability First：** 每个 KPI 卡片、时间线、待审批小部件对应的 API 必须在对应 Epic Freeze 后才接入真实数据；此前使用 MSW Mock。参见 [ISSUES.md §Backend Capability First Rule](../../../ISSUES.md)。
- [ ] **三态覆盖：** Loading（骨架屏 — 4 张 KPI 卡片 shimmer + 时间线骨架）、Empty（新用户首次登录无数据时显示引导文案）、Error（每个数据模块独立错误状态 + 重试按钮）。
- [ ] **响应式布局：** 桌面端 4 列 KPI + 双栏（时间线+待审批）；平板端 2 列 KPI + 上下堆叠；移动端单列 + 横向滚动项目进度卡片。
- [ ] WebSocket 断开时顶部 Banner 提示"实时更新已断开，正在重连…"（指数退避重连）

## API Contract

本页面消费以下已冻结 API（按 Freeze 阶段分阶段接入）：

| Freeze 阶段 | API | 用途 |
|------------|-----|------|
| E1A | `GET /api/v1/documents` | 文档数量统计 |
| E2 | `GET /api/v1/evidence/*` | 证据概览统计 |
| E3 | `WS /api/v1/ws/workflows/{id}` | 实时事件推送（时间线 + KPI 增量更新） |
| E3 | `GET /api/v1/artifacts?artifact_type=risk_finding` | 风险发现总数 |
| E4 | `GET /api/v1/approvals?status=pending` | 待审批数量 + 待审批列表 |
| E4 | `GET /api/v1/reports` | 报告统计 |
| E0 | `GET /api/v1/projects` | 活跃项目数 + 项目进度 |

```typescript
// 推荐后端聚合端点（MVP 后可优化）
// GET /api/v1/dashboard/summary
interface DashboardSummary {
  projects: ProjectStats;
  workflows: WorkflowStats;
  risks: RiskStats;
  approvals: ApprovalStats;
  recent_events: RecentEvent[];
  updated_at: string;
}

interface ProjectStats {
  active: number;
  total: number;
  change_from_last_week: number;    // 环比
}

interface WorkflowStats {
  completed_this_week: number;
  total_completed: number;
  change_from_last_week: number;
}

interface RiskStats {
  total: number;
  by_severity: {
    critical: number;
    high: number;
    medium: number;
    low: number;
  };
  change_from_last_week: number;
}

interface ApprovalStats {
  pending: number;
  pending_high: number;              // HIGH/CRITICAL 的待审批数
  approved_this_week: number;
}

interface RecentEvent {
  event_id: string;
  workflow_id: string;
  event_type: string;                // "AgentCompleted" | "RiskDetected" | "ArtifactCreated" | ...
  timestamp: string;                 // ISO 8601
  project_name: string;
  summary: string;                   // 人类可读摘要
  agent_name?: string;
  severity?: string;                 // 仅 RiskDetected
}

// WebSocket 增量事件（复用 E3 Event Contract）
// 前端监听并更新对应模块：
//   AgentCompleted    → 时间线追加 + Workflow KPI 更新
//   RiskDetected      → 时间线追加 + 风险 KPI 更新
//   ApprovalRequired  → 时间线追加 + 待审批小部件追加 + 审批 KPI 更新
//   WorkflowCompleted → 时间线追加 + 项目进度更新
```

## UI States

| 状态 | 表现 |
|------|------|
| **Initial Loading** | 4 张 KPI 卡片骨架屏（shimmer）+ 时间线 5 行骨架 + 待审批小部件骨架 |
| **Partial Data** | 各模块独立加载；已就绪模块正常显示，未就绪模块显示骨架屏 |
| **KPI Error** | 单张 KPI 卡片显示"加载失败" + 独立"重试"按钮，不影响其余卡片 |
| **Timeline Empty** | 时间线区域显示"暂无活动记录" + 引导文案"上传第一个文档开始审计" |
| **Approvals Empty** | 待审批小部件显示"暂无待审批事项 🎉" |
| **Projects Empty** | 项目进度区显示"暂无审计项目" + "创建第一个项目" CTA 按钮 |
| **WebSocket Disconnected** | 顶部黄色 Banner"实时更新已断开，正在重连…（第 N 次）" |
| **Global Error** | 整个 Dashboard 加载失败时显示错误插图 + "重新加载" 按钮 |
