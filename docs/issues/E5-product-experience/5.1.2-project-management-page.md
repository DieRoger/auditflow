# 5.1.2 — Project Management Page（项目管理页面）
- **Epic:** E5 Product Experience
- **Labels:** `frontend`, `crud`, `project`, `react`
- **Depends on:** E0 (Core Schema — tenants/users/audit_projects 表), E0.2 (Database Foundation)

## Description

实现 Project Management Page —— 审计项目的全生命周期管理页面。审计师在此创建、查看、编辑、归档审计项目（Audit Project），每个项目绑定被审计客户（client）、审计年度（engagement），作为所有后续 Workflow 的容器。

**核心交互：**
1. 项目列表支持搜索（名称/客户模糊匹配）、状态筛选（全部/审计中/已完成/已归档）、年度筛选、排序（创建时间/更新时间/名称）
2. 点击项目 → 右侧详情面板展开（基本信息 + Workflow 列表 + 操作按钮）
3. "新建项目"按钮 → 弹出模态框 → 填写表单 → POST 创建
4. "编辑"按钮 → 模态框预填当前值 → PUT 更新
5. "归档"按钮 → 二次确认 → 项目状态变更为 archived（软删除，不物理删除数据）
6. "删除"按钮 → 二次确认（含项目名称输入确认）→ DELETE（仅限 draft 状态且无 Workflow 的项目）

**前端技术约束（Backend Capability First）：**
- 依赖 E0 的 Core Schema（`audit_projects` 表），API 在 E0 阶段冻结
- 项目 CRUD API 归属 E0 Foundation，格式为 `GET/POST/PUT/DELETE /api/v1/projects`
- 使用 MSW Mock 开发，等待 E0 后端就绪

## Acceptance Criteria

- [ ] **项目列表：** 分页展示（默认每页 20 条），每条显示项目名称、客户名称、审计年度、状态标签（带颜色）、进度百分比条、风险摘要（HIGH/CRITICAL 计数）、最后更新时间（相对时间）
- [ ] **搜索与筛选：** 搜索框支持项目名称和客户名称模糊匹配（debounce 300ms）；状态下拉（全部/待开始/审计中/待审批/已完成/已归档）；年度下拉；排序下拉（最近更新/最近创建/名称 A-Z）
- [ ] **新建项目模态框：** 必填字段标记 *（项目名称、客户、年度）；客户支持下拉搜索（`GET /api/v1/clients`）；审计类型单选；表单验证（项目名称 ≥ 3 字符、年度有效范围）；提交按钮显示 Loading 状态
- [ ] **编辑项目：** 点击"编辑"→ 模态框预填当前数据 → 提交 PUT 更新 → 成功后列表即时刷新
- [ ] **归档项目：** 仅 `completed` 状态的项目可归档；二次确认对话框"归档后项目将变为只读，确认归档？"；归档后项目从默认列表隐藏（可通过状态筛选查看）
- [ ] **删除项目：** 仅 `draft` 状态且无关联 Workflow 的项目可删除；二次确认需输入项目名称以确认；删除后列表即时移除
- [ ] **项目详情面板：** 点击项目后右侧展示：基本信息区（客户、年度、类型、负责人、创建时间、备注）、Workflow 列表（关联的 Workflow 按时间倒序，点击跳转 Workflow Monitor）、操作按钮区（编辑/归档/删除）
- [ ] **Backend Capability First：** 项目 CRUD API 基于 E0 Core Schema 冻结的 Contract；前端不自行扩展未被后端实现的字段。参见 [ISSUES.md §Backend Capability First Rule](../../../ISSUES.md)。
- [ ] **三态覆盖：** Loading（列表骨架屏 5 行 shimmer）、Empty（搜索无结果时"未找到匹配项目"+ 清除筛选按钮；全局无项目时"创建第一个审计项目"CTA）、Error（列表区域错误提示 + 重试按钮；模态框提交错误 toast 通知）
- [ ] **响应式布局：** 桌面端左右两栏（列表 + 详情）；平板端列表全宽 + 详情底部抽屉（Drawer）；移动端单列列表 + 全屏详情页
- [ ] **乐观更新：** 归档/删除操作先更新 UI，请求失败时回滚 + toast 错误提示
- [ ] 项目状态流转遵循规则：`draft → active → completed → archived`（不可逆向，除非手动 intervention）

## API Contract

本页面消费 E0 Foundation 冻结的 Project CRUD API：

```typescript
// GET /api/v1/projects?search={q}&status={s}&year={y}&sort={field}&page={n}&page_size={n}
interface ProjectListResponse {
  items: ProjectItem[];
  total: number;
  page: number;
  page_size: number;
}

interface ProjectItem {
  project_id: string;
  name: string;
  client_id: string;
  client_name: string;
  engagement_year: number;           // 审计年度，如 2025
  audit_type: "annual" | "interim_review" | "special";
  status: "draft" | "active" | "completed" | "archived";
  progress: number;                  // 0–100，基于 Workflow 完成率
  risk_summary: {
    critical: number;
    high: number;
    medium: number;
    low: number;
  };
  owner_id: string;
  owner_name: string;
  created_at: string;                // ISO 8601
  updated_at: string;
  workflow_count: number;
}

// POST /api/v1/projects
interface CreateProjectRequest {
  name: string;                      // ≥ 3 字符
  client_id: string;
  engagement_year: number;
  audit_type: "annual" | "interim_review" | "special";
  owner_id?: string;
  notes?: string;
}

interface CreateProjectResponse {
  project_id: string;
  created_at: string;
}

// PUT /api/v1/projects/{project_id}
interface UpdateProjectRequest {
  name?: string;
  client_id?: string;
  engagement_year?: number;
  audit_type?: "annual" | "interim_review" | "special";
  owner_id?: string;
  notes?: string;
}

// DELETE /api/v1/projects/{project_id}
// — 仅 draft 状态 + 无关联 Workflow 时允许
// — 响应: 204 No Content

// POST /api/v1/projects/{project_id}/archive
// — 仅 completed 状态时允许
// — 响应: 200 { project_id, status: "archived", archived_at }

// GET /api/v1/clients?search={q}
// — 用于客户下拉搜索
interface ClientItem {
  client_id: string;
  name: string;
  industry?: string;
}
```

## UI States

| 状态 | 表现 |
|------|------|
| **Initial Loading** | 列表区域 5 行骨架屏（shimmer），筛选栏可见但 disabled |
| **Empty（全局）** | 居中插画 + "创建第一个审计项目" CTA 按钮，筛选栏隐藏 |
| **Empty（搜索/筛选无结果）** | 列表区域显示"未找到匹配项目" + "清除筛选条件"按钮 |
| **Project Selected** | 右侧详情面板展开，高亮选中项目行 |
| **Modal Creating** | 模态框打开 → 填写表单 → 提交按钮显示 spinner → 成功后模态框关闭 + toast "项目创建成功" |
| **Modal Editing** | 模态框预填当前值 → 提交按钮显示 spinner → 成功后模态框关闭 + 列表即时更新 |
| **Archiving** | 二次确认对话框 → 确认后项目行显示"归档中..." spinner → 成功后项目从默认列表移除 |
| **Deleting** | 二次确认（含名称输入）→ 确认后项目行移除 → toast "项目已删除" |
| **Error（列表加载）** | 列表区域错误提示 + "重新加载"按钮 |
| **Error（模态框提交）** | toast 错误通知（"项目创建失败：{原因}"），模态框保持打开 |
| **Error（归档/删除）** | toast 错误通知，乐观更新回滚 |
