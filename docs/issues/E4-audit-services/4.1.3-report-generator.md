# 4.1.3 — Report Generator（审计报告生成器）
- **Epic:** E4 Audit Services
- **Labels:** `service`, `report`, `template-rendering`, `compliance`
- **Depends on:** 3.2.5 (Reviewer Agent), 4.1.2 (Workpaper Generator)

## Description

实现 Report Generator —— 一个**模板渲染 Service**（非 Agent，无自主决策循环）。它将 Reviewer Agent 的审核结论 + 上游所有 Artifact 组装为符合 ISA 700 标准结构的审计报告草稿。

**ISA 700 标准审计报告结构：**
```
┌──────────────────────────────────────────┐
│ 独立审计报告                               │
├──────────────────────────────────────────┤
│ 1. 标题 & 收件人                          │
│ 2. 审计意见段（Opinion）                   │
│ 3. 意见基础段（Basis for Opinion）         │
│ 4. 关键审计事项段（Key Audit Matters）      │
│ 5. 管理层责任段                            │
│ 6. 审计师责任段                            │
│ 7. 签字 & 日期                            │
└──────────────────────────────────────────┘
```

**Service Flow：**
```
ReviewReportArtifact + WorkpaperArtifact + RiskFindingArtifact[]
    ↓
1. 数据聚合
   - ReviewReportArtifact → review_result、issues、quality_score
   - RiskFindingArtifact[] → 聚合为 Key Audit Matters
   - WorkpaperArtifact → 审计程序和证据摘要
   - AuditPlanArtifact → 审计范围和重要性水平
    ↓
2. 意见类型判定（确定性规则引擎）
   - review_result=APPROVED + quality_score ≥ 阈值 → 无保留意见
   - review_result=APPROVED + 有 issues + quality_score < 阈值 → 保留意见
   - review_result=NEEDS_REVISION → 无法表示意见（报告草稿标注"待复核"）
   - 判定逻辑完全确定性，无 LLM 参与
    ↓
3. 报告渲染
   - Jinja2 模板（ISA 700 结构）→ Markdown
   - Markdown → PDF（正式排版）
    ↓
4. 强制 HITL
   - next_action 强制设为 "HUMAN_REVIEW"
   - 报告草稿仅 CPA 签字后才可出具
```

**关键约束：**
- 意见类型判定使用**确定性规则引擎**，不经过 LLM（避免幻觉导致错误意见类型）
- 审计报告草稿永远标记为 DRAFT，需经 HITL Dashboard 审批后才可最终出具
- 报告中的 Key Audit Matters 自动从 HIGH/CRITICAL 风险中提取
- 报告引用所有来源（准则、工作底稿编号），形成完整可追溯链

## Acceptance Criteria

- [ ] 生成的报告包含 ISA 700 全部 7 个标准段
- [ ] 意见类型判定使用确定性规则（不经过 LLM），规则表：
  - `APPROVED + quality_score ≥ 0.80 → UNQUALIFIED（无保留意见）`
  - `APPROVED + quality_score < 0.80 → QUALIFIED（保留意见）`
  - `NEEDS_REVISION → DISCLAIMER（无法表示意见，标注"待复核"）`
  - `REJECTED → ADVERSE（否定意见）`
- [ ] Key Audit Matters 自动从 HIGH/CRITICAL RiskFinding 提取，每项含描述 + 审计应对
- [ ] 报告中的所有金额和比率保留自底稿数据，不做任何自动修改
- [ ] 支持 Markdown + PDF 双格式输出
- [ ] 报告草稿顶部有醒目的水印"DRAFT — 未经 CPA 签字确认"
- [ ] 生成后强制设置 `next_action = "HUMAN_REVIEW"`（API 返回中携带 approval_required=true）
- [ ] 产出的 ReportArtifact 写入 Artifact Registry
- [ ] WebSocket 推送 `ApprovalRequired` 事件，触发 HITL Dashboard 通知
- [ ] 模板可配置：支持不同国家/地区的 ISA 700 变体

## I/O Interface

```python
# POST /internal/services/report-generator/generate
class ReportGenerateRequest(BaseModel):
    workflow_id: str
    project_id: str
    review_artifact_id: str                # Reviewer Agent 产出的 ReviewReportArtifact.id
    workpaper_artifact_ids: list[str]      # 关联的工作底稿 Artifact ID 列表
    template_id: str                       # Jinja2 模板标识（默认 "isa700_standard"）
    output_format: Literal["markdown", "pdf", "both"]
    engagement_info: EngagementInfo

class EngagementInfo(BaseModel):
    client_name: str                       # 被审计单位名称
    fiscal_year: str                       # 会计年度
    report_date: date                      # 报告日期
    auditor_firm: str                      # 会计师事务所名称
    engagement_partner: str                # 签字 CPA 姓名
    addressed_to: str                      # 收件人（如"XX公司股东会"）

class ReportGenerateResponse(BaseModel):
    status: Literal["SUCCESS", "PARTIAL", "FAILED"]
    result: ReportResult | None
    approval_required: bool                # 始终为 True（强制 HITL）

class ReportResult(BaseModel):
    report_artifact_id: str                # 写入 Artifact Registry 后的 ID
    opinion_type: str                      # UNQUALIFIED | QUALIFIED | DISCLAIMER | ADVERSE
    opinion_basis_summary: str             # 意见基础摘要
    key_audit_matters: list[KeyAuditMatter]
    markdown_content: str | None
    pdf_url: str | None                    # MinIO presigned URL（带 DRAFT 水印）
    sections: ReportSections               # 结构化章节

class KeyAuditMatter(BaseModel):
    risk_id: str
    title: str
    description: str                       # 为何是关键事项
    audit_response: str                    # 审计如何应对
    related_workpaper_refs: list[str]      # 引用底稿编号

class ReportSections(BaseModel):
    title: str                             # "独立审计报告"
    addressee: str
    opinion: OpinionSection
    basis_for_opinion: BasisSection
    key_audit_matters: list[KeyAuditMatter]
    management_responsibility: str
    auditor_responsibility: str
    signature: SignatureSection

class OpinionSection(BaseModel):
    opinion_type: str
    opinion_text: str                      # 标准意见措辞
    emphasis_of_matter: str | None         # 强调事项段（如有）

class BasisSection(BaseModel):
    standards: list[str]                   # 遵循的审计准则
    independence: str                      # 独立性声明
    evidence_sufficiency: str

class SignatureSection(BaseModel):
    auditor_firm: str
    engagement_partner: str
    report_date: date
    city: str
```

## Evaluation

| L4 指标 | 说明 | 计算方式 | 目标 |
|---------|------|---------|------|
| **Opinion Correctness** | 意见类型准确性 | 确定性规则引擎输出与手工判定对比 | 100%（确定性） |
| **KAM Coverage** | 关键审计事项覆盖率 | HIGH+CRITICAL 风险全部出现在 KAM 中 | = 100% |
| **Report Structure Compliance** | 报告结构合规性 | ISA 700 7 段全部存在 | = 100% |
