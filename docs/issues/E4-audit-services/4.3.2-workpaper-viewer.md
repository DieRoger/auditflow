# 4.3.2 — Workpaper Viewer（工作底稿查看器）
- **Epic:** E4 Audit Services
- **Labels:** `frontend`, `workpaper`, `document-viewer`, `react`
- **Depends on:** 4.1.2 (Workpaper Generator)

## Description

实现 Workpaper Viewer —— 审计工作底稿的查看与复核界面。审计师在此页面浏览 Workpaper Generator（4.1.2）生成的工作底稿，支持 Markdown 渲染预览、PDF 内嵌查看、章节导航、以及底稿内 Citation 的交互式追溯。

**页面布局：**
```
┌──────────────────────────────────────────────────┐
│ 工作底稿 — 收入确认 FY2025                         │
├────────────┬─────────────────────────────────────┤
│ 章节导航    │ 底稿内容                              │
│ (左侧 TOC) │                                     │
│            │ §1 审计领域 & 认定                    │
│ §1 领域    │ ─────────────────                   │
│ §2 风险    │ 审计领域：Revenue Recognition         │
│ §3 程序    │ 认定：Existence, Accuracy, Cutoff     │
│ §4 证据    │ 期间：2025-01-01 ~ 2025-12-31        │
│ §5 结论    │                                     │
│ §6 签字    │ §2 识别的风险                         │
│            │ ─────────────────                   │
│            │ ⚠️ HIGH — 激进收入确认                │
│            │   可能性：72%                         │
│            │   指标：[1] 收入增长 45%              │
│            │        （行业均值 10%）               │
│            │                                     │
│            │ ┌─────────────────────────┐         │
│            │ │ Citation [1]:           │         │
│            │ │ ISA 240 ¶32 — 收入      │         │
│            │ │ 舞弊风险因素...          │         │
│            │ └─────────────────────────┘         │
│            │                                     │
│ 操作栏：   │                                     │
│ [↩ 退回]  │                                     │
│ [✏️ 批注] │                                     │
│ [📥 PDF]  │                                     │
└────────────┴─────────────────────────────────────┘
```

**核心交互：**
1. 左侧 TOC：按工作底稿 6 个章节生成导航，点击滚动到对应章节
2. 中间正文：Markdown 渲染（支持表格、列表、粗体/斜体），Citation 上标 [n] 可点击
3. Citation Popover：点击 Citation 上标 → 弹出浮层显示完整引用信息（来源、段落、原文）
4. 底稿复核操作：退回修改、添加批注、下载 PDF

## Acceptance Criteria

- [ ] 左侧 TOC 自动从 WorkpaperSections 生成，支持高亮当前阅读位置（Intersection Observer）
- [ ] Markdown 正文渲染使用 `react-markdown` + 自定义 Citation 组件（上标链接 `[n]`）
- [ ] Citation 点击 → Popover 浮层展示：
  - 来源类型（审计准则/客户文档/工作底稿）
  - 来源描述 + 段落号
  - 引用原文摘录（≤ 300 字符）
- [ ] 支持 PDF 内嵌预览（`<iframe>` 加载 MinIO presigned URL）和下载按钮
- [ ] 底稿复核操作栏：
  - "退回修改"按钮 → 调用 Approval API，决策为 `needs_revision`
  - "添加批注"按钮 → 选中文本后可添加批注（MVP 为简化版，存储为 comment）
  - "下载 PDF"按钮 → 触发 MinIO presigned URL 下载
- [ ] 批注列表：页面底部或侧边栏显示已有批注，按段落分组
- [ ] 三态覆盖：Loading（正文骨架屏）、Empty（"工作底稿尚未生成"）、Error（重试按钮）
- [ ] 响应式布局：桌面端 TOC + 正文两栏；移动端 TOC 折叠为汉堡菜单
- [ ] 底稿编制信息（编制人/复核人/日期）在页脚固定显示

## I/O Interface

```typescript
// API Contract（基于 E4 Report API v1 + Artifact Registry）

// GET /api/v1/artifacts/{artifact_id}?artifact_type=workpaper
interface WorkpaperDetailResponse {
  artifact_id: string;
  workflow_id: string;
  sections: WorkpaperSections;       // 同 4.1.2 WorkpaperSections
  markdown_content: string;
  pdf_url: string | null;
  metadata: WorkpaperMetadata;
  annotations: Annotation[];         // 批注列表
}

interface WorkpaperMetadata {
  prepared_by: string;
  prepared_date: string;
  reviewer: string;
  review_date: string | null;
  audit_area: string;
  period_end: string;
}

interface Annotation {
  id: string;
  section_id: string;                // 批注所属章节
  selected_text: string;             // 选中的文本
  comment: string;
  created_by: string;
  created_at: string;
  resolved: boolean;
}

// GET /api/v1/workpapers?project_id={id}
interface WorkpaperListResponse {
  items: WorkpaperListItem[];
  total: number;
}

interface WorkpaperListItem {
  artifact_id: string;
  audit_area: string;
  status: string;                    // "draft" | "under_review" | "approved"
  prepared_by: string;
  prepared_date: string;
  reviewer: string | null;
}
```

## UI States

| 状态 | 表现 |
|------|------|
| **Loading** | 左侧 TOC 骨架屏 + 右侧正文骨架屏（多行 pulse 动画） |
| **Empty（列表）** | 居中"该项目暂无工作底稿" + "生成底稿"按钮（触发 Workpaper Generator） |
| **Empty（底稿内容）** | 底稿已生成但章节为空 → 显示"底稿生成中，请稍候..." |
| **Error** | 正文区域显示错误信息 + "重新加载" + "重新生成"按钮 |
| **Citation Popover** | 点击 Citation [n] 弹出浮层，右上角 × 关闭，点击外部区域关闭 |
| **Annotation Active** | 选中文本后显示浮动工具栏"添加批注"，输入框自动聚焦 |
