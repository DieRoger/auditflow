# 4.2.1 — Approval Management Page（审批管理页面）
- **Epic:** E4 Audit Services
- **Labels:** `frontend`, `hitl`, `websocket`, `react`
- **Depends on:** 4.1.3 (Report Generator), 3.1.3 (Agent Execution API), E3 Workflow Events (WebSocket)

## Description

实现 Approval Management Page —— HITL（Human-In-The-Loop）Dashboard 的核心审批界面。审计师在此页面查看所有待审批事项（风险发现、工作底稿、审计报告），做出审批决策（通过/退回/拒绝），并查看实时推送的审批请求。

**页面布局：**
```
┌──────────────────────────────────────────────────┐
│ 审批管理                                          │
├────────────┬──────────────────┬──────────────────┤
│ 待审批列表  │ 详情卡片          │ 操作区            │
│ (左侧栏)   │ (中间主体)        │ (右侧)           │
│            │                  │                  │
│ ● 报告 #1  │ 审计报告草稿      │ [通过] [退回]     │
│   急❗      │ ISA 700 标准结构  │ [要求修改]       │
│            │ KAM: 3 项        │                  │
│ ● 风险 #3  │ Opinion: 无保留   │ 审批意见：        │
│   HIGH     │                  │ [_____________]  │
│            │ 完整预览 ↓        │                  │
│ ● 底稿 #2  │                  │ 签字确认：        │
│   待复核   │                  │ [_____________]  │
│            │                  │                  │
│ (WebSocket │                  │                  │
│  实时更新) │                  │                  │
└────────────┴──────────────────┴──────────────────┘
```

**核心交互：**
1. WebSocket 实时推送 `ApprovalRequired` 事件 → 新审批项自动出现在待审批列表
2. 点击审批项 → 中间区域展示详情（报告预览/风险详情/底稿内容）
3. 审批者做出决策 → POST `/api/v1/approvals` → 触发 `ApprovalSubmitted` 事件
4. 审批历史按 workflow_id 分组，支持筛选（待处理/已通过/已退回/全部）

**前端技术约束（Backend Capability First）：**
- 基于 API Freeze 的 Contract 开发（`POST /api/v1/approvals`、`GET /api/v1/approvals`）
- 使用 MSW（Mock Service Worker）进行 Mock 开发，等待后端 API 就绪
- 不使用尚未冻结的后端 Schema

## Acceptance Criteria

- [ ] 待审批列表按时间倒序排列，新到达的审批项自动置顶（WebSocket `ApprovalRequired` 事件驱动）
- [ ] 审批项卡片显示：类型（报告/风险/底稿）、严重程度/意见类型、提交时间、提交 Agent
- [ ] 点击审批项 → 详情面板展开（含完整内容预览，报告支持 Markdown/PDF 内嵌查看）
- [ ] 审批决策三按钮：✅ 通过 / ↩️ 退回修改 / ❌ 拒绝，均有二次确认弹窗
- [ ] 审批意见文本框（必填，最少 10 字符），支持审批模板快捷填充
- [ ] 签字确认字段（模拟 CPA 电子签名，MVP 阶段为文本框输入姓名）
- [ ] WebSocket 断开时显示重连提示 + 自动重连（指数退避）
- [ ] 审批历史页面：支持按 workflow_id、决策类型、日期范围筛选
- [ ] 三态覆盖：Loading（骨架屏）、Empty（"暂无待审批事项"插图）、Error（重试按钮）
- [ ] 审批提交后即时从待审批列表移除，移入历史列表
- [ ] 响应式布局：桌面端三栏，平板端堆叠，移动端单栏 + 底部操作栏

## I/O Interface

```typescript
// API Contract（基于 E4 API Freeze）

// GET /api/v1/approvals?status=pending&project_id={id}
interface ApprovalListResponse {
  items: ApprovalItem[];
  total: number;
  page: number;
  page_size: number;
}

interface ApprovalItem {
  approval_id: string;
  workflow_id: string;
  agent_name: string;              // 发起审批的 Agent 名称
  artifact_type: string;           // "risk_finding" | "workpaper" | "report"
  artifact_id: string;
  severity?: string;               // 风险等级（仅 risk_finding）
  opinion_type?: string;           // 意见类型（仅 report）
  summary: string;                 // 审批摘要（≤ 200 字符）
  status: "pending" | "approved" | "rejected" | "needs_revision";
  created_at: string;              // ISO 8601
  reviewed_by?: string;
  reviewed_at?: string;
}

// POST /api/v1/approvals
interface ApprovalSubmitRequest {
  approval_id: string;
  decision: "approved" | "rejected" | "needs_revision";
  comment: string;                 // 审批意见（≥ 10 字符）
  reviewer_signature: string;      // CPA 签字
}

// WebSocket Event: ApprovalRequired
interface ApprovalRequiredEvent {
  event_id: string;
  event_type: "ApprovalRequired";
  workflow_id: string;
  timestamp: string;
  payload: {
    approval_id: string;
    agent_name: string;
    severity: string;              // 仅风险相关
    summary: string;
  };
}

// WebSocket Event: ApprovalSubmitted
interface ApprovalSubmittedEvent {
  event_id: string;
  event_type: "ApprovalSubmitted";
  workflow_id: string;
  timestamp: string;
  payload: {
    approval_id: string;
    decision: string;
    comment: string;
  };
}
```

## UI States

| 状态 | 表现 |
|------|------|
| **Loading** | 左侧列表骨架屏（3 个 pulse 动画卡片），中间区域空白 |
| **Empty** | 居中文案"暂无待审批事项 🎉" + 插画 |
| **Error** | 列表区域显示错误信息 + "重新加载"按钮 |
| **Item Selected** | 中间详情面板渲染对应内容（Report/Markdown/PDF 预览），右侧操作区激活 |
| **Submitting** | 审批按钮显示 Loading spinner，禁止重复点击 |
| **WebSocket Disconnected** | 顶部显示黄色 Banner"实时推送已断开，正在重连..." |
