# 4.3.1 — Risk Page（风险评估页面）
- **Epic:** E4 Audit Services
- **Labels:** `frontend`, `risk`, `visualization`, `react`
- **Depends on:** 3.2.3 (Risk Agent), 4.1.1 (Planning Engine)

## Description

实现 Risk Page —— 审计风险评估的可视化展示页面。审计师在此页面查看 Risk Agent 产出的所有 `RiskFindingArtifact`，按审计领域分组浏览风险详情，查看风险等级分布，以及每个风险对应的审计程序建议和证据状态。

**页面布局：**

**核心交互：**
1. 左侧：风险概览（饼图/柱状图）+ 审计领域筛选器
2. 右侧：选中风险的详细信息（指标、程序、证据状态、准则引用）
3. 支持按严重程度排序和筛选
4. 每个风险项可展开查看完整的 Agent 推理链（`reasoning` 字段）

## Acceptance Criteria

- [ ] 风险概览面板展示：风险等级分布饼图（CRITICAL/HIGH/MEDIUM/LOW 四色）、各领域风险数量柱状图
- [ ] 审计领域筛选器：按领域分组，每个领域显示风险数量角标，支持多选/全选
- [ ] 风险列表支持按严重程度排序（默认 CRITICAL → LOW）、按时间排序
- [ ] 风险详情卡片展示：标题、严重程度 Badge（带颜色）、可能性进度条、指标列表、建议程序 Checklist、证据覆盖进度条
- [ ] 准则引用可点击展开，显示完整引用原文
- [ ] Agent 推理链可展开：显示 Risk Agent 的 reasoning 步骤列表
- [ ] 证据不足标记：证据覆盖率 < 阈值时显示黄色警告图标 + "证据待补充" 标签
- [ ] 三态覆盖：Loading（骨架屏）、Empty（"该领域无风险发现"）、Error（重试按钮）
- [ ] 响应式布局：桌面端左右两栏，移动端上下堆叠
- [ ] 风险详情中的程序 Checklist 点击后可跳转到 Workpaper Viewer（4.3.2）

## I/O Interface

```typescript
// API Contract（基于 E3 Agent Execution API + Artifact Registry）

// GET /api/v1/artifacts?workflow_id={id}&artifact_type=risk_finding
interface RiskFindingListResponse {
  items: RiskFindingItem[];
  summary: RiskSummary;
}

interface RiskSummary {
  total: number;
  by_severity: {
    critical: number;
    high: number;
    medium: number;
    low: number;
  };
  by_area: Record<string, number>;   // { "Revenue Recognition": 3, "AR Impairment": 2, ... }
}

interface RiskFindingItem {
  artifact_id: string;
  workflow_id: string;
  area: string;
  title: string;
  severity: "CRITICAL" | "HIGH" | "MEDIUM" | "LOW";
  probability: number;               // 0.0 ~ 1.0
  indicators: IndicatorDetail[];
  related_standards: StandardRef[];
  suggested_procedures: ProcedureSuggestion[];
  reasoning: string[];               // Agent 推理链
  evidence_coverage: number;         // 0.0 ~ 1.0
  created_at: string;
}

interface IndicatorDetail {
  text: string;
  citations: Citation[];
}

interface StandardRef {
  standard: string;                  // "IFRS 15"
  paragraph: string;                 // "¶27"
  excerpt: string;                   // 引用原文
}

interface ProcedureSuggestion {
  type: string;                      // "Inspection" | "Confirmation" | ...
  steps: string[];
  evidence_required: string[];
}

interface Citation {
  source_type: string;
  source_id: string;
  description: string;
  page_or_section: string;
}
```

## UI States

| 状态 | 表现 |
|------|------|
| **Loading** | 左侧领域列表骨架屏 + 右侧详情卡片骨架屏（shimmer 动画） |
| **Empty（全局）** | 居中"该审计项目暂无风险发现" + 插画 |
| **Empty（领域筛选后）** | 筛选结果为空时显示"该领域无匹配风险" |
| **Error** | 面板显示错误信息 + "重新加载"按钮 |
| **Risk Selected** | 右侧详情面板滚动到对应风险，高亮选中项 |
| **Reasoning Expanded** | 展开推理链步骤列表，每步带序号和描述 |
