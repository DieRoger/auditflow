# 4.1.1 — Planning Engine（审计计划引擎）
- **Epic:** E4 Audit Services
- **Labels:** `service`, `planning`, `deterministic`
- **Depends on:** 3.2.1 (Planner Agent), 0.5.1.2 (Artifact Contract)

## Description

实现 Planning Engine —— 一个**确定性计算 Service**（非 Agent，无自主决策循环）。Planner Agent（E3）输出 `AuditPlanArtifact` 中定义了审计计划的高层结构（procedures、assertions、ontology 引用），Planning Engine 负责将其中的公式计算部分落地：重要性水平（Materiality）计算、审计抽样（Sampling）策略参数求解、审计程序时间线编排。

**与 Planner Agent 的关系：**
- Planner Agent（Agent）：基于 Ontology 推理链决定"审哪些领域、用什么程序"
- Planning Engine（Service）：执行确定性公式计算和模板化排程

**Service Flow：**
```
AuditPlanArtifact（来自 Planner Agent）
    ↓
1. Materiality 计算
   - 输入：财务报表关键金额（总资产/总收入/税前利润）
   - 公式：基准金额 × 百分比 → 整体重要性水平
   - 公式：整体重要性水平 × 系数 → 实际执行重要性水平
   - 支持多基准（ISA 320 指南）
    ↓
2. Sampling 策略参数
   - 输入：总体金额、重要性水平、预期误差、置信水平
   - MUS 抽样：样本量 = f(总体, 重要性, 置信度)
   - 随机/分层抽样：参数计算
    ↓
3. Timeline 排程
   - 按 procedure 依赖关系和审计阶段生成时间线
    ↓
4. 回填 AuditPlanArtifact.content
   - 将计算结果写入 MaterialityCalc / SamplingStrategy / timeline
```

**关键约束：** 所有计算必须可复现、可审计。每个公式的输入参数和中间步骤均记录到 Audit Log（Append-Only Hash Chain，见 Issue 6.3.1）。

## Acceptance Criteria

- [ ] Materiality 计算支持 ≥3 个基准（总资产/总收入/税前利润），结果精确到小数点后 2 位
- [ ] 实际执行重要性水平 = 整体重要性 × 可配置系数（默认 0.75，可通过项目设置覆盖）
- [ ] MUS 抽样公式正确实现：`样本量 = (总体金额 × 置信系数) / (重要性水平 - 预期误差 × 扩展系数)`
- [ ] 支持随机抽样和分层抽样两种替代方法
- [ ] Timeline 按 procedure 间的 `depends_on` 关系拓扑排序，无循环依赖检测
- [ ] 所有计算输入/输出写入结构化日志（structlog），trace_id 可追溯
- [ ] 输入缺失（如未提供税前利润）→ 返回 `status=PARTIAL` + 明确缺失字段列表
- [ ] 计算结果写入 `AuditPlanArtifact.content`，通过 Artifact Registry 持久化
- [ ] 单元测试覆盖率 ≥ 90%（纯计算逻辑，高覆盖率要求）

## I/O Interface

```python
# POST /internal/services/planning-engine/calculate
class PlanningEngineRequest(BaseModel):
    workflow_id: str
    project_id: str
    plan_artifact_id: str                   # Planner Agent 产出的 AuditPlanArtifact.id

    # Materiality 输入
    financial_data: FinancialSummary        # 财务报表关键数据
    materiality_config: MaterialityConfig   # 重要性配置（基准选择、百分比、系数）

    # Sampling 输入
    population_amount: float                # 抽样总体金额
    expected_error: float                   # 预期误差金额
    confidence_level: float                 # 置信水平（默认 0.95）

    # Timeline 输入
    audit_start_date: date
    audit_end_date: date

class FinancialSummary(BaseModel):
    total_assets: float | None
    total_revenue: float | None
    profit_before_tax: float | None
    total_equity: float | None

class MaterialityConfig(BaseModel):
    base: str                               # "total_assets" | "total_revenue" | "profit_before_tax"
    percentage: float                       # 例如 0.5（总资产 0.5%）、5（税前利润 5%）
    performance_factor: float               # 默认 0.75

class PlanningEngineResponse(BaseModel):
    status: Literal["SUCCESS", "PARTIAL", "FAILED"]
    result: PlanningEngineResult | None
    errors: list[str]                       # PARTIAL/FAILED 时的错误详情

class PlanningEngineResult(BaseModel):
    # 回填到 AuditPlanArtifact.content 的确定性计算结果
    materiality: MaterialityCalc
    sampling_strategy: SamplingStrategy
    timeline: AuditTimeline
    computation_log: list[ComputationStep]  # 可审计的计算步骤

class MaterialityCalc(BaseModel):
    base_amount: float
    base_type: str
    percentage: float
    overall_materiality: float              # 整体重要性水平
    performance_materiality: float          # 实际执行重要性水平
    formula: str                            # 例如 "total_revenue * 0.5%"

class SamplingStrategy(BaseModel):
    method: str                             # "MUS" | "Random" | "Stratified"
    population_amount: float
    materiality: float
    expected_error: float
    confidence_level: float
    sample_size: int                        # 计算得出的样本量
    interval: float | None                  # MUS 抽样间隔
    formula: str                            # 例如 "pop * reliability_factor / (materiality - expected_error * expansion_factor)"

class AuditTimeline(BaseModel):
    phases: list[TimelinePhase]
    total_estimated_days: int

class TimelinePhase(BaseModel):
    phase_name: str                         # "Planning" | "Fieldwork" | "Completion"
    start_date: date
    end_date: date
    procedure_ids: list[str]                # 该阶段的 procedure ID 列表

class ComputationStep(BaseModel):
    step: int
    description: str                        # 中文描述：例如 "选择基准：总收入 ¥1,200,000,000"
    inputs: dict                            # 输入参数
    formula: str                            # 使用公式
    output: float | dict                    # 计算结果
```

## Evaluation

| L4 指标 | 说明 | 计算方式 | 目标 |
|---------|------|---------|------|
| **Materiality Accuracy** | 重要性计算准确性 | 与手工计算（审计专家）结果对比，误差 < 0.1% | 100% |
| **Sampling Correctness** | 抽样参数正确性 | MUS 公式与审计软件（如 IDEA/ACL）输出一致 | 100% |
