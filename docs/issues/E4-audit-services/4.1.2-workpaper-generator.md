# 4.1.2 — Workpaper Generator（工作底稿生成器）
- **Epic:** E4 Audit Services
- **Labels:** `service`, `workpaper`, `template-rendering`
- **Depends on:** 3.2.3 (Risk Agent), 3.2.4 (Evidence Agent), 2.2.1 (Citation Builder)

## Description

实现 Workpaper Generator —— 一个**模板渲染 Service**（非 Agent，无自主决策循环）。它将上游 Agent（Risk + Evidence）产出的结构化 Artifact 组装为符合审计实务标准的工作底稿。

**工作底稿结构（ISA 230 审计文档标准）：**
```
┌─────────────────────────────────────────┐
│ 工作底稿 — FY2025 Revenue Recognition   │
├─────────────────────────────────────────┤
│ 1. 审计领域 & 认定                       │
│ 2. 识别的风险（含风险等级 & 可能性）       │
│ 3. 执行的审计程序                        │
│ 4. 收集的证据（含 Citation 追溯）         │
│ 5. 审计结论                              │
│ 6. 编制人 / 复核人 / 日期                │
└─────────────────────────────────────────┘
```

**Service Flow：**
```
RiskFindingArtifact + EvidencePackageArtifact
    ↓
1. 数据组装
   - 从 Artifact Registry 按 workflow_id 拉取所有上游 Artifact
   - RiskFindingArtifact → 风险区域、等级、指标、推荐程序
   - EvidencePackageArtifact → 证据声明、来源、覆盖率
   - KnowledgePackageArtifact → 相关准则引用
    ↓
2. Citation 嵌入
   - 每个风险指标 → 嵌入对应 Citation（准则段落 / 文档页码 / 证据来源）
   - 生成 Citation 索引表
    ↓
3. 模板渲染
   - 将结构化数据注入 Jinja2 模板 → Markdown
   - Markdown → WeasyPrint/Playwright → PDF
    ↓
4. 输出 WorkpaperArtifact → Artifact Registry
```

**关键约束：** 模板渲染是确定性的（相同输入 → 相同输出）。Workpaper 中的所有 Claim 必须有 Citation 支撑，无引用的声明标记为 `[需补充证据]`。

## Acceptance Criteria

- [ ] 生成的 Markdown 工作底稿包含完整的 6 个标准部分（领域/风险/程序/证据/结论/编制信息）
- [ ] 所有 RiskFinding 的 indicator 均嵌入对应 Citation（准则引用或文档引用）
- [ ] Citation 索引表自动生成（编号 → 来源描述 → 页码/段落）
- [ ] 支持 Markdown 输出（用于预览 + 版本对比）
- [ ] 支持 PDF 输出（WeasyPrint 渲染，含页眉页脚/页码/事务所 Logo）
- [ ] 模板化：Jinja2 模板可配置（支持不同事务所的自定义模板）
- [ ] 证据覆盖率 < 阈值（默认 0.60）时，结论部分自动标注"证据不足"警告
- [ ] 编制人/复核人/日期字段从 workflow metadata 自动填充
- [ ] 产出的 WorkpaperArtifact 写入 Artifact Registry，parent_artifact_id 链接到 RiskFinding + EvidencePackage
- [ ] WebSocket 推送 `ArtifactCreated` 事件（artifact_type="workpaper"）

## I/O Interface

```python
# POST /internal/services/workpaper-generator/generate
class WorkpaperGenerateRequest(BaseModel):
    workflow_id: str
    project_id: str
    artifact_ids: list[str]                # 上游 Artifact ID 列表
    template_id: str                       # Jinja2 模板标识（默认 "isa230_default"）
    output_format: Literal["markdown", "pdf", "both"]
    metadata: WorkpaperMetadata

class WorkpaperMetadata(BaseModel):
    prepared_by: str                       # 编制人 user_id
    reviewer: str                          # 复核人 user_id
    audit_area: str                        # 审计领域
    period_end: date                       # 审计期间截止日

class WorkpaperGenerateResponse(BaseModel):
    status: Literal["SUCCESS", "PARTIAL", "FAILED"]
    result: WorkpaperResult | None
    warnings: list[str]                    # 如 "证据覆盖率 45%（低于阈值 60%）"

class WorkpaperResult(BaseModel):
    workpaper_artifact_id: str             # 写入 Artifact Registry 后的 ID
    markdown_content: str | None           # Markdown 原始内容
    pdf_url: str | None                    # MinIO presigned URL（PDF）
    sections: WorkpaperSections            # 结构化章节（用于前端分段渲染）

class WorkpaperSections(BaseModel):
    audit_area: AuditAreaSection
    risks: list[RiskSection]               # 每个风险一个条目
    procedures: list[ProcedureSection]
    evidence: EvidenceSection
    conclusion: ConclusionSection
    sign_off: SignOffSection
    citation_index: list[CitationEntry]

class AuditAreaSection(BaseModel):
    area_name: str                         # 如 "Revenue Recognition"
    assertions: list[str]                  # 相关认定
    period: str                            # 审计期间

class RiskSection(BaseModel):
    risk_id: str
    title: str
    severity: str                          # CRITICAL | HIGH | MEDIUM | LOW
    probability: float
    indicators: list[IndicatorWithCitation]
    related_standards: list[str]

class IndicatorWithCitation(BaseModel):
    text: str
    citations: list[Citation]              # 该指标的证据/准则引用

class ProcedureSection(BaseModel):
    procedure_id: str
    type: str
    steps: list[str]
    results: str                           # 执行结果摘要

class EvidenceSection(BaseModel):
    claims: list[EvidencedClaim]
    coverage: float                        # 有证据的 claim 比例
    unmatched: list[str]                   # 无证据支持的 claim

class ConclusionSection(BaseModel):
    summary: str
    issues_identified: list[str]
    recommendation: str
    evidence_sufficiency: str              # "SUFFICIENT" | "INSUFFICIENT"

class SignOffSection(BaseModel):
    prepared_by: str
    prepared_date: datetime
    reviewer: str
    review_date: datetime | None

class CitationEntry(BaseModel):
    index: int                             # [1], [2], ...
    source_type: str                       # AUDIT_STANDARD | CLIENT_DOCUMENT | WORKPAPER
    source_description: str                # 如 "ISA 500 ¶6"
    page_or_section: str
    excerpt: str                           # 引用原文片段
```

## Evaluation

| L4 指标 | 说明 | 计算方式 | 目标 |
|---------|------|---------|------|
| **Citation Embedding Rate** | Citation 嵌入率 | 有 Citation 的 indicator / 总 indicator | = 100% |
| **Workpaper Structure Completeness** | 底稿结构完整性 | 6 个标准节全部存在且非空 | = 100% |
| **PDF Rendering Fidelity** | PDF 渲染保真度 | 人工检查 Markdown→PDF 无丢失/变形 | 通过 |
