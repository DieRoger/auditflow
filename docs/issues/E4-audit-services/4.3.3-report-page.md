# 4.3.3 — Report Page（审计报告页面）
- **Epic:** E4 Audit Services
- **Labels:** `frontend`, `report`, `document-viewer`, `compliance`, `react`
- **Depends on:** 4.1.3 (Report Generator), 4.2.1 (Approval Management Page)

## Description

实现 Report Page —— 审计报告草稿的查看与最终审批页面。审计师在此页面浏览 Report Generator（4.1.3）生成的 ISA 700 标准审计报告草稿，查看关键审计事项（KAM），确认报告内容后提交最终审批。

**页面布局：**
```
┌──────────────────────────────────────────────────────┐
│ 审计报告 — XX公司 FY2025                              │
├────────────────────────────────┬─────────────────────┤
│ 报告预览（A4 比例）             │ 报告元数据            │
│                                │                     │
│ ┌────────────────────────────┐ │ 意见类型：           │
│ │                            │ │ ✅ 无保留意见         │
│ │    独立审计报告              │ │                     │
│ │                            │ │ 质量评分：87/100     │
│ │ XX公司股东会：              │ │                     │
│ │                            │ │ 关键审计事项：        │
│ │ 一、审计意见                │ │ 1. 收入确认 (HIGH)   │
│ │ 我们审计了XX公司财务报表...  │ │ 2. 应收账款减值       │
│ │                            │ │    (HIGH)           │
│ │ 二、意见基础                │ │ 3. 存货跌价 (MEDIUM) │
│ │ 我们按照国际审计准则...      │ │                     │
│ │                            │ │ 签字 CPA：           │
│ │ 三、关键审计事项            │ │ [_______________]   │
│ │ ...                        │ │                     │
│ │                            │ │ [提交最终审批]       │
│ │ ⚠️ DRAFT — 未经 CPA 签字   │ │ [下载 PDF]          │
│ └────────────────────────────┘ │                     │
│                                │                     │
└────────────────────────────────┴─────────────────────┘
```

**核心交互：**
1. 报告 A4 预览：Markdown/HTML 渲染的报告正文，模拟纸张比例展示，顶部醒目 DRAFT 水印
2. 报告元数据面板：意见类型 Badge、质量评分进度条、KAM 列表（可点击展开详情）
3. 签字确认：CPA 姓名字段 + "提交最终审批"按钮（调用 Approval API）
4. 与 Approval Management Page（4.2.1）形成闭环：审批通过后报告状态变更为 FINAL，水印移除

**ISA 700 结构联动：**
- 报告的 7 个标准段在页面中分节渲染
- KAM 段每条可展开，链接回 Risk Page（4.3.1）的对应风险详情
- 意见基础段可展开查看遵循的审计准则列表

## Acceptance Criteria

- [ ] 报告预览区域以 A4 比例渲染（210mm × 297mm 等比例缩放），支持滚动查看
- [ ] 报告顶部醒目的红色 DRAFT 水印条纹（半透明 + 旋转 −30° + "DRAFT — 未经 CPA 签字确认"）
- [ ] 报告 7 个标准段完整渲染：标题/收件人 → 意见段 → 意见基础段 → KAM 段 → 管理层责任 → 审计师责任 → 签字
- [ ] 意见类型 Badge 使用颜色区分：
  - 无保留意见 → 绿色 `UNQUALIFIED`
  - 保留意见 → 黄色 `QUALIFIED`
  - 无法表示意见 → 橙色 `DISCLAIMER`
  - 否定意见 → 红色 `ADVERSE`
- [ ] 质量评分以圆形进度条展示（0-100），低于 80 分用橙色警告色
- [ ] KAM 列表：每条 KAM 可展开 → 显示详细描述 + 审计应对 + 关联底稿引用
- [ ] KAM 项点击"查看风险详情"→ 跳转到 Risk Page（4.3.1）对应 risk_id
- [ ] 签字确认区：CPA 姓名输入框 + 电子签名（MVP 阶段文本框）+ "提交最终审批"按钮
- [ ] "提交最终审批"→ POST `/api/v1/approvals` → 成功后报告状态变为 `awaiting_approval`
- [ ] 审批通过后（通过 WebSocket `ApprovalSubmitted` 事件）→ 水印自动切换为"APPROVED" 绿色标记
- [ ] "下载 PDF"按钮 → 触发 MinIO presigned URL 下载（通过审批的报告不含 DRAFT 水印）
- [ ] 三态覆盖：Loading（A4 纸骨架屏）、Empty（"报告尚未生成"）、Error（重试按钮）
- [ ] 响应式布局：桌面端 A4 预览 + 侧边栏；移动端 A4 预览占满宽度，元数据在底部折叠面板

## I/O Interface

```typescript
// API Contract（基于 E4 Report API v1）

// GET /api/v1/reports/{artifact_id}
interface ReportDetailResponse {
  artifact_id: string;
  workflow_id: string;
  opinion_type: "UNQUALIFIED" | "QUALIFIED" | "DISCLAIMER" | "ADVERSE";
  quality_score: number;                     // 0–100
  status: "draft" | "awaiting_approval" | "approved" | "rejected";
  sections: ReportSections;                  // 同 4.1.3 ReportSections
  key_audit_matters: KeyAuditMatterDetail[];
  markdown_content: string;
  pdf_url: string | null;
  engagement_info: EngagementInfo;
  approval_history: ApprovalEvent[];
}

interface KeyAuditMatterDetail {
  risk_id: string;
  title: string;
  description: string;
  audit_response: string;
  related_workpaper_refs: string[];
}

interface EngagementInfo {
  client_name: string;
  fiscal_year: string;
  report_date: string;
  auditor_firm: string;
  engagement_partner: string;
  addressed_to: string;
}

interface ApprovalEvent {
  decision: string;
  comment: string;
  reviewer: string;
  timestamp: string;
}

// GET /api/v1/reports?project_id={id}
interface ReportListResponse {
  items: ReportListItem[];
  total: number;
}

interface ReportListItem {
  artifact_id: string;
  client_name: string;
  fiscal_year: string;
  opinion_type: string;
  status: string;
  quality_score: number;
  created_at: string;
}
```

## UI States

| 状态 | 表现 |
|------|------|
| **Loading** | A4 纸比例骨架屏（shimmer 动画模拟文本行）+ 侧边栏元数据骨架屏 |
| **Empty** | 居中"审计报告尚未生成" + "生成报告"按钮（触发 Report Generator） |
| **Error** | A4 预览区域显示错误信息 + "重新加载" + "重新生成"按钮 |
| **Draft（默认）** | 报告顶部红色半透明 DRAFT 水印，操作区显示"提交最终审批" |
| **Awaiting Approval** | 水印变为黄色"AWAITING APPROVAL"，操作区显示"等待审批中..."（禁用） |
| **Approved** | 水印变为绿色"APPROVED"标记，操作区显示"已通过 — CPA: {姓名}"，可下载正式 PDF |
| **Rejected** | 水印变为红色"REJECTED"，显示拒绝原因，操作区显示"重新生成"按钮 |
| **KAM Expanded** | 展开 KAM 详情面板，显示完整描述 + 审计应对 + 底稿引用链接 |
