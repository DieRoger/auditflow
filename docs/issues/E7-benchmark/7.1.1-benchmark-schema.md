# 7.1.1 — Benchmark Schema
- **Epic:** E7 Benchmark Expansion
- **Labels:** `benchmark`, `evaluation`, `schema`
- **Depends on:** E0.5 Evaluation Core（0.5.3.2 EvaluationRunner）

## Description
定义 Benchmark 数据格式与 YAML Schema，作为所有 benchmark case 的统一结构规范。每个 scenario 对应一个 `benchmark/{scenario}/benchmark.yaml`，包含 case 元数据、输入数据、预期输出（risks、assertions、procedures、evidence_min_count、related_standards）以及评估指标配置。该 Schema 是 7.1.2（20 Cases × 7 领域）和 7.1.3（Baseline Evaluation Report）的前置依赖。

## Acceptance Criteria
- [ ] YAML Schema 定义完整，覆盖所有必需字段：`name`, `scenario`, `cases[]`（id, description, documents, input, expected, evaluation）
- [ ] `input` 段支持结构化财务数据注入（如 `financial_data`）
- [ ] `expected` 段涵盖：`risks`（area + severity + indicators）、`assertions`、`procedures`（type + target）、`evidence_min_count`、`related_standards`
- [ ] `evaluation` 段定义 `primary_metric` 与 `secondary_metrics`
- [ ] Schema 通过 EvaluationRunner 格式校验

## I/O Interface / Schema
```yaml
# benchmark/{scenario}/benchmark.yaml
name: revenue_audit_v1
scenario: Revenue Recognition Audit
cases:
  - id: rev_001
    description: "激进收入确认 — 收入增长 3x 行业均值"
    documents: [annual_report_sample.pdf, sales_contract_sample.pdf]
    input:
      financial_data: {revenue_growth: "45%", industry_avg: "10%", receivable_days: 120}
    expected:
      risks:
        - area: Revenue Recognition
          severity: HIGH
          indicators: ["revenue_growth > 3x avg", "receivable_days increased >30% YoY"]
      assertions: [Existence, Accuracy, Cutoff]
      procedures:
        - type: Inspection, target: [sales_contracts, shipping_docs]
        - type: Confirmation, target: [top5_customers]
      evidence_min_count: 3
      related_standards: ["IFRS 15 ¶27", "ISA 240 ¶32"]
    evaluation:
      primary_metric: risk_classification_accuracy
      secondary_metrics: [citation_completeness, procedure_coverage, reasoning_quality]
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | string | Benchmark 唯一标识 |
| `scenario` | string | 审计场景名称 |
| `cases[].id` | string | Case 唯一 ID（如 `rev_001`） |
| `cases[].documents` | []string | 关联模拟文档列表 |
| `cases[].input.financial_data` | map | 注入的结构化财务指标 |
| `cases[].expected.risks` | []Risk | 预期风险项（area, severity, indicators） |
| `cases[].expected.assertions` | []Assertion | 预期审计断言 |
| `cases[].expected.procedures` | []Procedure | 预期审计程序（type, target） |
| `cases[].expected.evidence_min_count` | int | 最少证据条目数 |
| `cases[].expected.related_standards` | []string | 相关会计准则/审计准则引用 |
| `cases[].evaluation.primary_metric` | string | 主评估指标 |
| `cases[].evaluation.secondary_metrics` | []string | 辅助评估指标 |
