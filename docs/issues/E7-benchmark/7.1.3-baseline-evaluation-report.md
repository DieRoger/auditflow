# 7.1.3 — Baseline Evaluation Report
- **Epic:** E7 Benchmark Expansion
- **Labels:** `benchmark`, `evaluation`, `ci/cd`
- **Depends on:** 7.1.2 20 Cases × 7 领域

## Description
在 7.1.2 构建的 20 Cases 数据集上，运行 Baseline 对比评估：GPT-4 Direct（无 RAG）、Naive RAG（基础检索 + LLM）、AuditFlow E3（Agent Core Runtime 完整流水线），生成 Baseline Evaluation Report。同时将评估集成到 CI 流水线中：当新 Prompt 版本在 Benchmark 上的主指标分数低于 Baseline 时，PR 应被自动 Block。

## Acceptance Criteria
- [ ] Baseline Comparison 记录完整，包含三组对照：
  - **GPT-4 Direct**：纯 LLM 推理，无文档检索
  - **Naive RAG**：基础向量检索 + LLM 推理
  - **AuditFlow E3**：Agent Core Runtime 完整流水线（含 Evidence Agent、Risk Agent、Reviewer）
- [ ] 评估指标覆盖：`risk_classification_accuracy`（主指标）、`citation_completeness`、`procedure_coverage`、`reasoning_quality`（辅助指标）
- [ ] Baseline Report 输出为结构化 JSON + Markdown 可读报告
- [ ] CI 集成：新 Prompt 版本主指标分数 < Baseline（E3 基准）→ PR Blocked
- [ ] CI 检查作为 GitHub Actions / 等价 CI Step 运行
- [ ] Baseline 数据版本化存储，支持后续 re-baseline

## I/O Interface / Schema
### Baseline Report JSON Schema
```yaml
# evaluation/reports/baseline_v1.yaml
baseline_id: baseline_v1
created_at: "2025-07-01T00:00:00Z"
benchmark_version: 7.1.2
runs:
  - run_id: gpt4_direct
    model: gpt-4-turbo
    configuration: {rag: false, agents: false}
    aggregate_scores:
      risk_classification_accuracy: 0.62
      citation_completeness: 0.00
      procedure_coverage: 0.45
      reasoning_quality: 0.58
  - run_id: naive_rag
    model: gpt-4-turbo
    configuration: {rag: "basic_vector", agents: false}
    aggregate_scores:
      risk_classification_accuracy: 0.71
      citation_completeness: 0.55
      procedure_coverage: 0.60
      reasoning_quality: 0.65
  - run_id: auditflow_e3
    model: gpt-4-turbo
    configuration: {rag: "auditflow", agents: true}
    aggregate_scores:
      risk_classification_accuracy: 0.85  # ← CI Gate Baseline
      citation_completeness: 0.82
      procedure_coverage: 0.80
      reasoning_quality: 0.83
```

### CI Gate 逻辑（伪代码）
```
if new_prompt_score["risk_classification_accuracy"] < baseline_e3["risk_classification_accuracy"]:
    block_pr("主指标低于 Baseline，请检查 Prompt 变更")
```
