# 6.4.1 — RBAC
- **Epic:** E6 Production & Compliance
- **Labels:** `security`, `rbac`
- **Depends on:** 0.2.1 (Core Schema — users 表)

## Description

实现基于角色的访问控制（Role-Based Access Control），定义四个角色及其权限边界。MVP Beta 阶段实现 RBAC 骨架（非商业化多租户完整权限），确保核心审计流程的权限最小化。

**四个角色：**

| 角色 | 权限范围 | 典型用户 |
|------|---------|---------|
| **Admin** | 全系统管理：用户管理、租户配置、系统设置、所有数据 CRUD | 系统管理员 |
| **Auditor** | 审计执行：创建项目、上传文档、运行 Workflow、查看所有 Agent 产出、生成底稿/报告 | 审计师（核心用户） |
| **Reviewer** | 审计复核：审批/退回 Agent 产出、查看所有 Workflow 数据、不可修改 Agent 产出 | 审计经理 / 合伙人 |
| **Viewer** | 只读访问：查看已完成项目的报告和底稿、不可运行 Workflow、不可审批 | 客户 / 外部审计 |

**权限矩阵：**

| 操作 | Admin | Auditor | Reviewer | Viewer |
|------|-------|---------|----------|--------|
| 用户管理 | ✅ | ❌ | ❌ | ❌ |
| 创建审计项目 | ✅ | ✅ | ❌ | ❌ |
| 上传文档 | ✅ | ✅ | ❌ | ❌ |
| 运行 Workflow | ✅ | ✅ | ❌ | ❌ |
| 查看 Agent 产出 | ✅ | ✅ | ✅ | ✅ |
| 审批/退回 | ❌ | ❌ | ✅ | ❌ |
| 生成底稿/报告 | ✅ | ✅ | ❌ | ❌ |
| 查看报告 | ✅ | ✅ | ✅ | ✅ |
| 查看 Audit Log | ✅ | ❌ | ✅ | ❌ |
| 系统配置 | ✅ | ❌ | ❌ | ❌ |

**实现方式：** FastAPI Dependency + `Depends(require_role(...))`，在路由层拦截。

## Acceptance Criteria

- [ ] `users` 表增加 `role` 字段（ENUM: `admin | auditor | reviewer | viewer`）
- [ ] FastAPI `require_role(*roles)` Dependency（自动从 JWT / Session 提取用户角色并校验）
- [ ] 所有 API endpoint 声明所需角色（`Depends(require_role("auditor"))`）
- [ ] 越权访问返回 `403 Forbidden` + 日志记录
- [ ] Alembic migration 包含 `role` 字段默认值（新用户默认 `viewer`）
- [ ] 种子数据：Admin 用户（`admin@auditflow.local`）+ Auditor 用户
- [ ] 单元测试：每个角色的允许/禁止操作矩阵全覆盖

## I/O Interface

```sql
-- 角色枚举
CREATE TYPE user_role_enum AS ENUM ('admin', 'auditor', 'reviewer', 'viewer');

-- users 表增加 role 字段
ALTER TABLE users ADD COLUMN role user_role_enum NOT NULL DEFAULT 'viewer';

CREATE INDEX idx_users_role ON users (role);
```

```python
# FastAPI RBAC Dependency
from functools import wraps
from fastapi import Depends, HTTPException, status

def require_role(*allowed_roles: str):
    """FastAPI Dependency：校验当前用户角色是否在允许列表中。"""
    async def role_checker(current_user: User = Depends(get_current_user)):
        if current_user.role not in allowed_roles:
            raise HTTPException(
                status_code=status.HTTP_403_FORBIDDEN,
                detail=f"Role '{current_user.role}' not allowed. Required: {allowed_roles}",
            )
        return current_user
    return role_checker

# 使用示例
@router.post("/workflows/{workflow_id}/execute")
async def execute_workflow(
    workflow_id: UUID,
    current_user: User = Depends(require_role("admin", "auditor")),
):
    ...
```
