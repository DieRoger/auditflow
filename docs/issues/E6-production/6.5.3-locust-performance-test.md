# 6.5.3 — Locust 性能测试
- **Epic:** E6 Production & Compliance
- **Labels:** `testing`, `performance`
- **Depends on:** E4 Audit Services (完整 Workflow API 可用), 6.5.1 (Prod Docker Compose)

## Description

使用 Locust 进行系统级性能测试，验证 AuditFlow 在生产负载下的吞吐量、延迟和稳定性。重点测试核心审计 Workflow 端到端场景（而非孤立 API 压测），确保系统在真实审计工作负载下满足 SLA。

**测试场景（3 类）：**

| 测试类型 | 场景 | 目标并发 | SLA 目标 |
|---------|------|---------|---------|
| **Baseline Load** | 5 并发 Workflow × 10 min | 5 users | P95 Latency < 30s（端到端 Workflow） |
| **Sustained Load** | 10 并发 Workflow × 30 min | 10 users | P95 Latency < 60s，错误率 < 1% |
| **Spike Test** | 瞬时 20 并发 → 回落到 5 | 5→20→5 | 无 OOM / Crash / 死锁 |

**关键测量指标：**

| 指标 | 采集方式 | 目标 |
|------|---------|------|
| **端到端 Workflow 延迟** | Locust Response Time | P50 < 20s / P95 < 60s（Sustained） |
| **Agent 执行延迟** | Prometheus `agent_execution_duration_seconds` | per Agent P95 |
| **LLM API 调用延迟** | Prometheus + Span Attributes | P95 < 10s |
| **数据库连接池利用率** | PostgreSQL `pg_stat_activity` | < 80% |
| **Redis 内存使用** | Redis `INFO memory` | < 70% |
| **错误率** | Locust Failures / Prometheus | < 1% |
| **Token 消耗速率** | `llm_token_consumption_total` rate | 监控基准 |

**测试数据：** 使用 E7 Benchmark 中的 3 个端到端 Case（Revenue / AR / Inventory）作为测试数据。

```python
# tests/performance/locustfile.py
"""
AuditFlow 端到端 Workflow 性能测试。

模拟完整审计 Workflow 生命周期：
1. 创建审计项目
2. 上传文档（PDF）
3. 触发 Workflow 执行（Planner → Knowledge → Risk → Evidence → Reviewer）
4. 等待 HITL（如果需要）
5. 获取最终报告

注意：每个 Locust User 模拟一个独立审计师。
"""

import time
from locust import HttpUser, task, between, events

class AuditWorkflowUser(HttpUser):
    """模拟审计师执行完整审计 Workflow。"""

    wait_time = between(30, 60)  # Workflow 之间有间隔（模拟真实思考时间）

    def on_start(self):
        """登录并获取 JWT Token。"""
        resp = self.client.post("/api/v1/auth/login", json={
            "email": "auditor@auditflow.local",
            "password": "test123",
        })
        self.token = resp.json()["access_token"]
        self.client.headers.update({
            "Authorization": f"Bearer {self.token}",
        })

    @task(1)
    def full_audit_workflow(self):
        """端到端审计 Workflow（核心压测场景）。"""
        # 1. 创建审计项目
        project_resp = self.client.post("/api/v1/projects", json={
            "name": f"Perf Test - {time.time()}",
            "client_id": "perf_client",
            "engagement_id": "FY2025",
        })
        project_id = project_resp.json()["id"]

        # 2. 上传文档（使用预置测试 PDF）
        with open("tests/fixtures/sample_annual_report.pdf", "rb") as f:
            doc_resp = self.client.post(
                f"/api/v1/projects/{project_id}/documents",
                files={"file": ("annual_report.pdf", f, "application/pdf")},
            )
        document_id = doc_resp.json()["id"]

        # 3. 等待文档处理完成（轮询）
        self._wait_for_processing(document_id)

        # 4. 触发 Workflow
        workflow_resp = self.client.post(f"/api/v1/projects/{project_id}/workflows", json={
            "workflow_type": "full_audit",
            "document_ids": [document_id],
        })
        workflow_id = workflow_resp.json()["id"]

        # 5. 轮询 Workflow 状态直到完成
        self._wait_for_workflow(workflow_id, timeout=300)  # 5 min 超时

        # 6. 获取报告（验证产出）
        self.client.get(f"/api/v1/projects/{project_id}/reports/latest")

    def _wait_for_processing(self, document_id: str, timeout: int = 60):
        """轮询等待文档解析完成。"""
        start = time.time()
        while time.time() - start < timeout:
            resp = self.client.get(f"/api/v1/documents/{document_id}")
            if resp.json()["status"] == "READY":
                return
            time.sleep(2)
        raise TimeoutError(f"Document {document_id} processing timeout")

    def _wait_for_workflow(self, workflow_id: str, timeout: int = 300):
        """轮询等待 Workflow 完成。"""
        start = time.time()
        while time.time() - start < timeout:
            resp = self.client.get(f"/api/v1/workflows/{workflow_id}")
            status = resp.json()["status"]
            if status in ("COMPLETED", "FAILED"):
                if status == "FAILED":
                    raise RuntimeError(f"Workflow {workflow_id} failed")
                return
            time.sleep(5)
        raise TimeoutError(f"Workflow {workflow_id} timeout after {timeout}s")
```

    count(*) AS total_connections,
    count(*) FILTER (WHERE state = 'active') AS active,
    count(*) FILTER (WHERE state = 'idle') AS idle,
    count(*) FILTER (WHERE wait_event IS NOT NULL) AS waiting

FROM pg_stat_statements
WHERE mean_exec_time > 1000
