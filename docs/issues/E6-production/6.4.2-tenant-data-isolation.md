# 6.4.2 — Tenant Data Isolation
- **Epic:** E6 Production & Compliance
- **Labels:** `security`, `multi-tenant`
- **Depends on:** 0.2.1 (Core Schema — tenants / audit_projects)

## Description

实现租户级数据隔离 —— 确保审计事务所之间的数据严格不可互见。采用 PostgreSQL Row-Level Security (RLS) + 应用层自动注入隔离键的双重保障。

**隔离维度：**

| 维度 | 键 | 说明 |
|------|-----|------|
| 一级隔离 | `firm_id` | 审计事务所（不同事务所的数据绝对隔离） |
| 二级隔离 | `engagement_id` | 审计委托（同一事务所的不同项目互不可见） |

**实现策略：**

1. **PG Row-Level Security：** 对核心业务表启用 RLS，`USING (firm_id = current_setting('app.current_firm_id'))`
2. **应用层自动注入：** 所有 Repository / DAO 查询方法在内部自动追加 `WHERE firm_id = $current_firm_id AND engagement_id = $current_engagement_id`，调用方无法绕过
3. **VectorStore 隔离：** `VectorStore.search()` 接口强制执行 `firm_id` + `engagement_id` 过滤（已在 ADR-003 中冻结）
4. **Session 级上下文：** 每个 API 请求在 middleware 层设置 `app.current_firm_id` / `app.current_engagement_id`（从 JWT / 请求上下文提取）

## Acceptance Criteria

- [ ] 核心业务表（`audit_projects` / `documents` / `workflows` / `artifacts`）启用 PG RLS
- [ ] RLS Policy：`USING (firm_id = current_setting('app.current_firm_id'))`
- [ ] FastAPI middleware 在请求开始时设置 `app.current_firm_id` + `app.current_engagement_id`
- [ ] 所有 Repository 查询方法内部自动注入 `firm_id` + `engagement_id` 过滤（通过 BaseRepository 基类强制）
- [ ] `VectorStore.search()` 强制执行隔离（ADR-003 已锁定接口签名）
- [ ] 单元测试：跨事务所查询返回空（firm_id=A 查询 firm_id=B 的数据）
- [ ] 单元测试：跨委托查询返回空（同一 firm 下 engagement_id=A 查询 engagement_id=B 的数据）
- [ ] 集成测试：绕过 Repository 直接写 SQL 时 RLS 仍然生效

## I/O Interface

```sql
-- ============================================================================
-- PostgreSQL Row-Level Security 配置
-- ============================================================================

-- 1. 对所有核心业务表启用 RLS
ALTER TABLE tenants ENABLE ROW LEVEL SECURITY;
ALTER TABLE audit_projects ENABLE ROW LEVEL SECURITY;
ALTER TABLE documents ENABLE ROW LEVEL SECURITY;
ALTER TABLE workflows ENABLE ROW LEVEL SECURITY;
ALTER TABLE artifacts ENABLE ROW LEVEL SECURITY;
ALTER TABLE embedding_item ENABLE ROW LEVEL SECURITY;

-- 2. 创建 RLS Policy（租户隔离）
--    注意：tenants 表自身也需要 RLS，但 admin 可以 bypass
CREATE POLICY tenant_isolation ON audit_projects
    FOR ALL
    USING (firm_id = current_setting('app.current_firm_id'))
    WITH CHECK (firm_id = current_setting('app.current_firm_id'));

CREATE POLICY tenant_isolation ON documents
    FOR ALL
    USING (firm_id = current_setting('app.current_firm_id'))
    WITH CHECK (firm_id = current_setting('app.current_firm_id'));

CREATE POLICY tenant_isolation ON workflows
    FOR ALL
    USING (firm_id = current_setting('app.current_firm_id'))
    WITH CHECK (firm_id = current_setting('app.current_firm_id'));

CREATE POLICY tenant_isolation ON artifacts
    FOR ALL
    USING (firm_id = current_setting('app.current_firm_id'))
    WITH CHECK (firm_id = current_setting('app.current_firm_id'));

CREATE POLICY tenant_isolation ON embedding_item
    FOR ALL
    USING (firm_id = current_setting('app.current_firm_id'))
    WITH CHECK (firm_id = current_setting('app.current_firm_id'));

-- 3. 管理员 Bypass RLS 策略（可选）
CREATE POLICY admin_bypass ON audit_projects
    FOR ALL
    USING (current_setting('app.current_user_role') = 'admin');
```

```python
# FastAPI Middleware：设置请求级隔离上下文
from fastapi import Request
from starlette.middleware.base import BaseHTTPMiddleware

class TenantIsolationMiddleware(BaseHTTPMiddleware):
    """在每个请求开始时设置 PostgreSQL session 级变量。"""

    async def dispatch(self, request: Request, call_next):
        # 从 JWT / Session 提取隔离键
        firm_id = request.state.user.firm_id
        engagement_id = request.state.user.engagement_id  # 可选
        role = request.state.user.role

        # 设置 PostgreSQL runtime 参数（RLS 使用）
        async with request.app.state.db_pool.acquire() as conn:
            await conn.execute(
                "SELECT set_config('app.current_firm_id', $1, true)", firm_id
            )
            await conn.execute(
                "SELECT set_config('app.current_user_role', $1, true)", role
            )
            if engagement_id:
                await conn.execute(
                    "SELECT set_config('app.current_engagement_id', $1, true)",
                    engagement_id,
                )

        response = await call_next(request)
        return response
```

```python
# BaseRepository：自动注入隔离键
class BaseRepository:
    def __init__(self, db: AsyncSession, context: RequestContext):
        self.db = db
        self.firm_id = context.firm_id
        self.engagement_id = context.engagement_id

    def _base_query(self, stmt: Select) -> Select:
        """所有查询自动追加隔离条件 — 子类无法绕过。"""
        table = stmt.froms[0]  # 假设单表查询
        if hasattr(table.c, 'firm_id'):
            stmt = stmt.where(table.c.firm_id == self.firm_id)
        if self.engagement_id and hasattr(table.c, 'engagement_id'):
            stmt = stmt.where(table.c.engagement_id == self.engagement_id)
        return stmt
```
