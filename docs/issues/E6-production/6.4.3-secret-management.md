# 6.4.3 — Secret Management
- **Epic:** E6 Production & Compliance
- **Labels:** `security`, `secrets`
- **Depends on:** 0.1.1 (仓库骨架 — `.env.example`)

## Description

实现密钥安全管理 —— 所有敏感凭证（API Key、数据库密码、JWT Secret、加密密钥）统一通过环境变量注入，禁止任何形式的硬编码。MVP Beta 阶段使用 `python-dotenv` + `.env` 文件，生产环境建议升级到 Vault / AWS Secrets Manager。

**密钥清单：**

| 密钥 | 用途 | 安全等级 |
|------|------|----------|
| `OPENAI_API_KEY` | OpenAI LLM API 调用 | CRITICAL |
| `DEEPSEEK_API_KEY` | DeepSeek LLM API 调用 | CRITICAL |
| `DATABASE_URL` | PostgreSQL 连接串（含密码） | CRITICAL |
| `REDIS_URL` | Redis 连接串（含密码） | HIGH |
| `MINIO_ROOT_USER` / `MINIO_ROOT_PASSWORD` | MinIO 对象存储凭证 | HIGH |
| `JWT_SECRET` | JWT Token 签名密钥 | CRITICAL |
| `ENCRYPTION_KEY` | 静态数据加密密钥（AES-256） | CRITICAL |
| `GRAFANA_ADMIN_PASSWORD` | Grafana 管理密码 | MEDIUM |

**安全规则：**

1. **所有 Key 走环境变量** — 禁止在代码、配置文件、注释中硬编码
2. **`.env` 不入 Git** — `.gitignore` 中强制排除 `.env`，仅提交 `.env.example`（含占位符）
3. **structlog 不记录 Secrets** — 日志自动脱敏（0.3.3 已实现）
4. **CI/CD 注入** — Secret 值通过 GitHub Secrets → CI Environment Variables 注入，不出现在任何 CI 日志中
5. **生产环境 → Vault** — MVP Beta 后迁移到 HashiCorp Vault 或云原生 Secrets Manager

## Acceptance Criteria

- [ ] `.env.example` 含所有必需的环境变量声明（值用 `<CHANGE_ME>` 占位）
- [ ] `.gitignore` 中 `.env` 强制排除
- [ ] `app/core/config.py` 使用 `pydantic-settings` 的 `BaseSettings` 加载所有配置（`SecretStr` 类型用于敏感字段）
- [ ] 应用启动时校验所有必需环境变量已设置（缺失 → 启动失败 + 明确错误信息）
- [ ] `SecretStr` 的 `__repr__` / `__str__` 返回 `'**********'`，不会意外泄漏到日志
- [ ] CI Pipeline 通过 GitHub Secrets 注入 `OPENAI_API_KEY` 等敏感变量（不写在 workflow YAML 中）
- [ ] 全局代码扫描 CI 步骤（`detect-secrets` / `gitleaks`）— 检测硬编码密钥 → PR Blocked
- [ ] 文档：生产环境密钥管理升级路径（Vault / AWS Secrets Manager）

```python
# app/core/config.py — pydantic-settings BaseSettings
from pydantic_settings import BaseSettings
from pydantic import SecretStr, Field

class Settings(BaseSettings):
    # ── LLM ──────────────────────────────────────────
    openai_api_key: SecretStr = Field(..., validation_alias="OPENAI_API_KEY")
    deepseek_api_key: SecretStr = Field(..., validation_alias="DEEPSEEK_API_KEY")

    # ── Database ─────────────────────────────────────
    database_url: SecretStr = Field(..., validation_alias="DATABASE_URL")
    redis_url: SecretStr = Field(..., validation_alias="REDIS_URL")

    # ── Storage ──────────────────────────────────────
    minio_root_user: str = Field(..., validation_alias="MINIO_ROOT_USER")
    minio_root_password: SecretStr = Field(..., validation_alias="MINIO_ROOT_PASSWORD")

    # ── Security ─────────────────────────────────────
    jwt_secret: SecretStr = Field(..., validation_alias="JWT_SECRET")
    encryption_key: SecretStr = Field(..., validation_alias="ENCRYPTION_KEY")

    # ── Observability ────────────────────────────────
    grafana_admin_password: SecretStr = Field(..., validation_alias="GRAFANA_ADMIN_PASSWORD")

    model_config = {
        "env_file": ".env",
        "env_file_encoding": "utf-8",
        "case_sensitive": False,
    }

settings = Settings()  # 启动时自动校验所有必需字段

# SecretStr 安全行为：
# >>> print(settings.openai_api_key)
# '**********'
# >>> settings.openai_api_key.get_secret_value()
# 'sk-proj-abc123...'
```

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run tests
        env:
          OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
          # DATABASE_URL / REDIS_URL 使用 CI 容器的本地值，不注入 Secret
        run: make test

  secret-scan:
    runs-on: ubuntu-latest

      - uses: actions/checkout@v4
