# 6.1.3 — L3 Grounding Evaluation
- **Epic:** E6 Production & Compliance
- **Labels:** `evaluation`, `grounding`
- **Depends on:** E0.5 Evaluation Runner, 2.2.2 (Grounding Checker)

## Description

实现 L3 Grounding 层评估 —— 检测 Agent 产出中的声明（Claim）是否有据可查。L3 是审计合规性的关键技术保障：每一个风险判断、每一项审计结论都必须能追溯到源文档或审计准则的具体段落。

**评估指标：**

| 指标 | 公式 | 说明 |
|------|------|------|
| **Citation Precision** | \|Valid Citations\| / \|Total Citations\|| 引用中有多少确实支持其声明 |
| **Citation Recall** | \|Valid Citations\| / \|Claims Requiring Citation\|| 需要引用的声明中有多少实际提供了引用 |
| **Unsupported Claim Rate** | \|Unsupported Claims\| / \|Total Claims\|| 无引用支撑的声明占比 |

**评估流程：**
```
1. 从 Agent 产出 Artifact 中提取所有 Claim + Citation 对
2. 对每个 (Claim, Citation) 调用 GroundingChecker.verify()：
   a. 检索 Citation 指向的源文档段落
   b. NLI（Natural Language Inference）判断源段落是否支撑 Claim
   c. 输出：SUPPORTED | CONTRADICTED | NEUTRAL
3. 聚合统计 Citation Precision / Recall / Unsupported Claim Rate
4. 标记所有 CONTRADICTED（幻觉）和 NEUTRAL（弱支撑）的 Claim
5. 生成 L3 Evaluation Report → CI 集成
```

**Grounding Checker 接入时机：** 在每个 Agent 产出 Artifact 后，Reviewer Agent 审查前自动调用。L3 评估是 Reviewer Agent 的核心 Tools 之一（`grounding_checker` tool）。

## Acceptance Criteria

- [ ] `GroundingChecker.verify(claim, citation)` → `SUPPORTED | CONTRADICTED | NEUTRAL`
- [ ] NLI 模型集成（可选：LLM-as-Judge 备选方案）
- [ ] `EvaluationRunner` 支持 L3 指标：Citation Precision / Recall / Unsupported Claim Rate
- [ ] 按 Agent 分组输出 L3 指标（哪个 Agent 的幻觉率高）
- [ ] CONTRADICTED Claim 自动标记为 "Potential Hallucination" 并触发 Reviewer 审查
- [ ] CI 集成：Citation Precision < 0.90 或 Unsupported Claim Rate > 0.05 → PR Blocked
- [ ] L3 Report 含 per-Claim 明细（Claim 文本、Citation 源段落、NLI 结果、置信度）

## I/O Interface

```python
# GroundingChecker 接口
class GroundingChecker(ABC):
    @abstractmethod
    async def verify(
        self,
        claim: str,
        citation: Citation,
    ) -> GroundingResult: ...

class GroundingResult(BaseModel):
    verdict: Literal["SUPPORTED", "CONTRADICTED", "NEUTRAL"]
    confidence: float                    # 0–1
    source_excerpt: str                  # Citation 指向的源文档段落原文
    reasoning: str                       # NLI 推理说明

# L3 Evaluation Result Schema
class L3EvaluationResult(BaseModel):
    artifact_id: str
    agent_name: str
    metrics: L3Metrics
    claim_details: list[ClaimVerificationDetail]

class L3Metrics(BaseModel):
    citation_precision: float            # Valid / Total
    citation_recall: float               # Valid / Claims Requiring
    unsupported_claim_rate: float        # Unsupported / Total Claims

class ClaimVerificationDetail(BaseModel):
    claim_text: str
    citation_ref: str                    # 引用标记（如 "ISA 240 ¶32"）
    verdict: str                         # SUPPORTED | CONTRADICTED | NEUTRAL
    confidence: float
    source_excerpt: str
    is_hallucination: bool               # CONTRADICTED → True
```

```sql
-- L3 评估结果持久化表
CREATE TABLE evaluation_l3_result (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    artifact_id VARCHAR NOT NULL,
    agent_name VARCHAR NOT NULL,
    citation_precision FLOAT NOT NULL,
    citation_recall FLOAT NOT NULL,
    unsupported_claim_rate FLOAT NOT NULL,
    claim_details JSONB NOT NULL,        -- ClaimVerificationDetail[]
    hallucination_count INT DEFAULT 0,   -- CONTRADICTED Claim 数量
    evaluated_at TIMESTAMPTZ DEFAULT now()
);

CREATE INDEX idx_eval_l3_agent ON evaluation_l3_result (agent_name, evaluated_at DESC);
```
