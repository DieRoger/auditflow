# 2.1.2 — Hybrid Merge + Reranker
- **Epic:** E2 Retrieval & Evidence Engine
- **Labels:** `search`, `backend`, `core`, `ai`
- **Depends on:** 2.1.1 (Vector Search + Keyword Search)

## Description

实现 Reciprocal Rank Blending (RRB) 融合算法，将 Vector Search 与 Keyword Search 两路结果合并为单一候选列表；再通过 CrossEncoder 重排序模型对合并后的候选列表逐条打分，输出最终排序结果。

**RRB 算法：**
```
score_rrb(doc) = Σ 1 / (k + rank_i(doc))
# rank_i: doc在通道i中的排名 (1-based)
# k: 平滑常数，默认 60
```

**CrossEncoder Reranker：** 使用 `sentence-transformers` 的 CrossEncoder 模型（如 `cross-encoder/ms-marco-MiniLM-L-6-v2`），对每个 `(query, document_text)` 对进行相关性打分，以 CrossEncoder 分数作为最终排序依据。支持批量推理以降低延迟。

**缓存策略：** 相同 `(query_hash, filters_hash)` 在 TTL 内命中缓存直接返回，避免重复调用 LLM Reranker。

## Acceptance Criteria

- [ ] `POST /api/v1/search/hybrid` — 输入 `query_text` + `top_k` + `filters`，内部并行调用 vector/keyword、RRB 融合、CrossEncoder 重排序，返回 `list[ScoredHit]`
- [ ] RRB 算法正确实现，`k` 可配置（默认 60）
- [ ] CrossEncoder 模型可配置（通过环境变量 `CROSS_ENCODER_MODEL`），支持 CPU/GPU 推理
- [ ] 批量推理：一次 CrossEncoder 调用处理所有候选对，batch_size 可配置
- [ ] 缓存层：Redis 缓存结果，TTL 默认 300s，key 为 `sha256(query + canonical_filters)`
- [ ] OpenTelemetry span 记录：`vector_hits`、`keyword_hits`、`merged_hits`、`reranker_latency_ms`
- [ ] 降级策略：CrossEncoder 不可用 → 仅 RRB 结果返回（不阻塞检索）
- [ ] L1 Evaluation 指标可采集：`Recall@5`、`MRR`、`NDCG@10`（供 E6 的 Evaluation Runner 调用）

## I/O Interface

```python
# 请求
class HybridSearchRequest(BaseModel):
    query_text: str
    top_k: int = 20
    filters: SearchFilters              # 同 2.1.1
    use_cache: bool = True
    vector_weight: float = 1.0          # 可在 RRB 前对 vector rank 加权（可选扩展）
    keyword_weight: float = 1.0         # 可在 RRB 前对 keyword rank 加权（可选扩展）

# 响应（复用 2.1.1 的 ScoredHit / SearchResponse）
class HybridSearchResponse(SearchResponse):
    vector_hits_count: int
    keyword_hits_count: int
    merged_count: int                   # RRB 融合后去重数量
    reranker_model: str                 # 实际使用的 CrossEncoder 模型名
    cached: bool

# API
POST /api/v1/search/hybrid → HybridSearchResponse

# 内部组件
class RRBBlender:
    def blend(
        self,
        vector_hits: list[ScoredHit],
        keyword_hits: list[ScoredHit],
        k: float = 60.0
    ) -> list[ScoredHit]: ...

class CrossEncoderReranker:
    async def rerank(
        self,
        query: str,
        candidates: list[ScoredHit],
        top_k: int
    ) -> list[ScoredHit]: ...

class HybridSearchService:
    def __init__(self, search_svc: SearchService, blender: RRBBlender, reranker: CrossEncoderReranker): ...
    async def hybrid_search(self, request: HybridSearchRequest) -> HybridSearchResponse: ...
```
