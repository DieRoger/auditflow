# 2.2.2 — Grounding Checker
- **Epic:** E2 Retrieval & Evidence Engine
- **Labels:** `evidence`, `evaluation`, `backend`, `ai`
- **Depends on:** 2.2.1 (Evidence Collector + Citation Builder)

## Description

实现事实性接地检查器（Grounding Checker），用于验证 Agent 产出的声明是否被引用的证据实际支持。这是 L3 Evaluation（Grounding）的核心组件，也是 Reviewer Agent（Issue 3.2.5）的关键依赖。

**检查维度：**
1. **Citation Precision** — 被引用的 evidence 是否真的支持对应 claim？（避免虚假引用）
2. **Citation Recall** — 所有 factual claim 是否都有对应 citation？（避免无引用断言）
3. **Unsupported Claim Rate** — 有多少比例的 claim 在证据中找不到支撑？

**实现方案：** 使用 LLM-as-Judge 模式，将 `(claim, cited_excerpt)` 对发送给模型进行蕴含关系判断（entailment / neutral / contradiction）。`entailment` → grounded，否则 → ungrounded。

**性能优化：** 批量并发发送 claim-evidence 对到 LLM，避免串行调用；缓存相同 `(claim_hash, excerpt_hash)` 的判断结果。

## Acceptance Criteria

- [ ] `POST /api/v1/evidence/grounding-check` — 输入 `claims: list[EvidencedClaim]`，返回 `GroundingReport`
- [ ] 每条 claim 的每个 evidence_item 进行 entailment 判断，三分类：`ENTAILMENT` | `NEUTRAL` | `CONTRADICTION`
- [ ] 汇总指标：`citation_precision`、`citation_recall`、`unsupported_claim_rate`
- [ ] 对每个 unsupported claim 输出具体原因（`NEUTRAL` 或 `CONTRADICTION` + 简短解释）
- [ ] 支持 `strict_mode`：严格模式下 `NEUTRAL` 也视为 unsupported；宽松模式仅 `CONTRADICTION` 视为 unsupported
- [ ] LLM-as-Judge prompt 模板化（Prompt Registry），可独立评估 prompt 变更对 grounding 的影响
- [ ] 缓存层：相同 `(claim_hash, excerpt_hash)` 在 TTL 内复用判断结果（Redis，TTL 默认 3600s）
- [ ] L3 Evaluation 指标可直接供 E6.1.3 Evaluation Runner 消费
- [ ] OpenTelemetry span：`grounding_claim_count`、`grounding_entailment_rate`、`grounding_latency_ms`

## I/O Interface

```python
# 请求
class GroundingCheckRequest(BaseModel):
    claims: list[EvidencedClaim]          # 来自 2.2.1
    strict_mode: bool = False             # True → NEUTRAL 视为 unsupported
    use_cache: bool = True

# 响应
class GroundingReport(BaseModel):
    report_id: str
    per_claim_results: list[ClaimGroundingResult]
    # 汇总指标（L3 Evaluation 直接消费）
    citation_precision: float             # entailment_count / total_citation_checks
    citation_recall: float                # claims_with_any_entailment / total_claims
    unsupported_claim_rate: float         # claims_with_zero_entailment / total_claims
    total_claims: int
    total_citation_checks: int
    model: str                            # LLM-as-Judge 使用的模型
    strict_mode: bool

class ClaimGroundingResult(BaseModel):
    claim_text: str
    is_grounded: bool                     # 至少一个 evidence 为 ENTAILMENT
    per_evidence: list[EvidenceGroundingVerdict]
    grounding_summary: str                # "2/3 citations support this claim"

class EvidenceGroundingVerdict(BaseModel):
    evidence_id: str
    citation_id: str
    verdict: Literal["ENTAILMENT", "NEUTRAL", "CONTRADICTION"]
    explanation: str                      # LLM 给出的简短理由（≤200 字符）
    confidence: float                     # LLM 自评置信度

# API
POST /api/v1/evidence/grounding-check → GroundingReport

# 内部服务接口
class GroundingChecker:
    async def check(self, request: GroundingCheckRequest) -> GroundingReport: ...
```
