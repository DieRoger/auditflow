# 2.3.1 — Evidence Browser + Citation Graph
- **Epic:** E2 Retrieval & Evidence Engine
- **Labels:** `frontend`, `evidence`, `visualization`
- **Depends on:** 2.2.1 (Evidence Collector + Citation Builder), E5 Foundation (基础 Layout/组件库)

## Description

构建证据浏览器（Evidence Browser）页面与引用关系图（Citation Graph）可视化组件，使用户能够查看和追溯审计证据的全貌。

**Evidence Browser 页面：**
- 左侧：Claim 列表，显示每条 claim 的 grounding 状态（绿色/黄色/红色图标）
- 右侧：选中 claim 后展示对应的 evidence 详情（原文摘录、来源文档、页码、相关度分数）
- 顶部工具栏：搜索/过滤 claim、导出 EvidencePackage 为 PDF/CSV

**Citation Graph（React Flow）：**
- 节点类型：`ClaimNode`（声明）、`EvidenceNode`（证据）、`SourceNode`（来源文档）
- 边类型：`SUPPORTS`（证据支持声明）、`SOURCED_FROM`（证据来源于文档）
- 交互：点击节点高亮关联子图、hover 显示摘要卡片、双击跳转原文
- 布局：Dagre 自动布局，自上而下（Claim → Evidence → Source）

**数据来源：** 通过 `GET /api/v1/evidence/{artifact_id}` 获取 `EvidencePackageArtifact`，前端解析 `claims` 和 `citations` 构建图数据。

## Acceptance Criteria

- [ ] **Evidence Browser 页面** — `/evidence/:artifactId`
  - [ ] 左侧 Claim 面板：列表展示，每条显示 claim 文本 + grounding 状态指示器（ENTAILMENT=绿 / NEUTRAL=黄 / CONTRADICTION=红 / 无证据=灰）
  - [ ] 右侧 Evidence 面板：选中 claim 后展示所有关联 evidence，每条含原文摘录、来源文档名、相关度分数、页码（如有）
  - [ ] 顶部工具栏：按 claim 文本搜索（前端过滤）、导出 EvidencePackage 为 JSON（下载按钮）
  - [ ] 响应式布局：移动端自动切换为单栏上下布局

- [ ] **Citation Graph 组件** — 嵌入 Evidence Browser 或独立 `/evidence/:artifactId/graph`
  - [ ] 三种节点类型：`ClaimNode` / `EvidenceNode` / `SourceNode`，使用不同颜色/图标区分
  - [ ] 两种边类型：`SUPPORTS`（实线绿）和 `SOURCED_FROM`（虚线灰）
  - [ ] 点击节点：高亮该节点及其 1-hop 邻居，其余节点透明度 0.3
  - [ ] Hover 节点：弹出 Tooltip 摘要卡片（claim 文本 / evidence 摘录 / source 文档名）
  - [ ] 双击 EvidenceNode/SourceNode：新标签页打开原文（如有 URL）或展开全文 panel
  - [ ] Dagre 自动布局：自上而下分层排列（Claim → Evidence → Source）
  - [ ] 缩放/平移/小地图（React Flow minimap）

- [ ] **状态覆盖**
  - [ ] 加载态：Skeleton placeholder
  - [ ] 空态：EvidencePackage 无 claims 时显示空提示「暂无证据记录」
  - [ ] 错误态：API 失败时显示 ErrorBoundary + 重试按钮

- [ ] **依赖要求**
  - [ ] 仅消费 E2 冻结的 `GET /api/v1/evidence/{artifact_id}` 接口
  - [ ] 使用 MSW Mock 数据独立开发（前端不依赖后端真实运行）

## I/O Interface

```typescript
// 前端数据模型（来自 API 响应反序列化）

interface EvidencePackage {
  artifact_id: string;
  artifact_type: "evidence_package";
  content: EvidencePackageContent;
  citations: Citation[];
}

interface EvidencePackageContent {
  claims: EvidencedClaim[];
  coverage: number;
  unmatched: string[];
}

interface EvidencedClaim {
  claim_text: string;
  evidence_items: EvidenceItem[];
}

interface EvidenceItem {
  evidence_id: string;
  citation: Citation;
  relevance_score: number;
}

interface Citation {
  citation_id: string;
  document_name: string;
  source_id: string;
  source_type: "CLIENT_DOCUMENT" | "AUDIT_STANDARD" | "WORKPAPER";
  excerpt: string;
  page_number: number | null;
  paragraph_number: number | null;
}

// React Flow 图数据构建
interface CitationGraphData {
  nodes: (
    | { id: string; type: "claim"; data: { text: string; grounded: boolean } }
    | { id: string; type: "evidence"; data: { excerpt: string; score: number; citationId: string } }
    | { id: string; type: "source"; data: { documentName: string; sourceType: string } }
  )[];
  edges: (
    | { id: string; source: string; target: string; type: "SUPPORTS" }
    | { id: string; source: string; target: string; type: "SOURCED_FROM" }
  )[];
}

// API 调用
GET /api/v1/evidence/{artifact_id} → EvidencePackage
```
