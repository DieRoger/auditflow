# 2.1.1 — Vector Search + Keyword Search
- **Epic:** E2 Retrieval & Evidence Engine
- **Labels:** `search`, `backend`, `core`
- **Depends on:** 0.3.2 (Embedding Service + VectorStore), 1A.2.1 (文档解析与分块), 1B.2.2 (Knowledge Embedding)

## Description

实现双路检索通道：基于 PGVector HNSW 索引的稠密向量检索（语义相似度），以及基于 PostgreSQL `tsvector` 的稀疏关键词全文检索（BM25/精确匹配）。两路独立运行，各自返回 `top_k` 结果及评分，为 2.1.2 Hybrid Merge 提供原始候选集。

**检索范围限制：** 每次检索必须通过 `firm_id`、`engagement_id`、`source_type`、`security_level` 四维过滤器进行租户与权限隔离，不允许跨租户检索。

**设计约束：**
- 向量检索使用 PGVector 的 HNSW 索引（`ivfflat` 作为 fallback），`ef_search` 可配置
- 关键词检索使用 PostgreSQL 原生 `tsvector` + `tsquery`，中文分词采用 `zhparser` 或 pg_jieba 扩展
- `source_type` 枚举：`CLIENT_DOCUMENT` | `AUDIT_STANDARD` | `WORKPAPER` | `RISK_CASE`
- `security_level` 枚举：`PUBLIC` | `INTERNAL` | `CONFIDENTIAL` | `RESTRICTED`

## Acceptance Criteria

- [ ] `POST /api/v1/search/vector` — 输入 `query_text` + `top_k` + `filters`，返回 `list[ScoredHit]`（含 `source_id`、`content_snippet`、`score`、`metadata`）
- [ ] `POST /api/v1/search/keyword` — 输入 `query_text` + `top_k` + `filters`，返回 `list[ScoredHit]`
- [ ] 两路均支持四维过滤：`firm_id` / `engagement_id` / `source_type` / `security_level`
- [ ] Vector Search 的 PGVector HNSW 索引创建完毕，`ef_search` 默认 100
- [ ] Keyword Search 的 `tsvector` 列 + GIN 索引创建完毕，中文分词可用
- [ ] OpenTelemetry span 记录每次检索的 `query`、`hit_count`、`top_score`、`latency_ms`
- [ ] 单元测试：相同 query 在不同 `source_type` 过滤下返回不同结果集
- [ ] 无跨租户泄漏：`firm_id` 过滤必然生效（集成测试验证）

## I/O Interface

```python
# 请求
class SearchRequest(BaseModel):
    query_text: str
    top_k: int = 20
    filters: SearchFilters

class SearchFilters(BaseModel):
    firm_id: str                          # 必填 — 租户隔离
    engagement_id: str | None = None      # 可选 — 限定审计年度
    source_type: str | None = None        # CLIENT_DOCUMENT | AUDIT_STANDARD | WORKPAPER | RISK_CASE
    security_level: str | None = None     # PUBLIC | INTERNAL | CONFIDENTIAL | RESTRICTED
    metadata_filters: dict[str, str] | None = None  # 额外过滤条件

# 响应
class ScoredHit(BaseModel):
    source_id: str
    source_type: str
    content_snippet: str                  # 截取 300 字符
    score: float
    metadata: dict

class SearchResponse(BaseModel):
    hits: list[ScoredHit]
    query: str
    latency_ms: float

# API
POST /api/v1/search/vector    → SearchResponse
POST /api/v1/search/keyword   → SearchResponse

# 内部服务接口（供 2.1.2 Hybrid Merge 调用）
class SearchService:
    async def vector_search(self, query_text: str, top_k: int, filters: SearchFilters) -> SearchResponse: ...
    async def keyword_search(self, query_text: str, top_k: int, filters: SearchFilters) -> SearchResponse: ...
```
