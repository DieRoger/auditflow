# 2.2.1 — Evidence Collector + Citation Builder
- **Epic:** E2 Retrieval & Evidence Engine
- **Labels:** `evidence`, `backend`, `core`
- **Depends on:** 2.1.2 (Hybrid Merge + Reranker)

## Description

以 Hybrid Search 为基础，构建证据收集器（Evidence Collector）和引用构建器（Citation Builder）。Evidence Collector 接收一组待验证的 `claims`（声明），对每条 claim 执行 Hybrid Search，从检索结果中筛选相关 Chunk 作为证据。Citation Builder 将筛选后的 Chunk 转化为符合审计追溯标准的 `Citation` 对象。

**Evidence Collector 流程：**
```
claims_to_verify → [对每条 claim 执行 hybrid_search] → [去重/合并 Chunks]
→ [按 claim 分组 evidence] → EvidencePackageArtifact
```

**Citation 格式要求：**
- 每条 Evidence 必须包含精确来源引用：文档名、页码（如适用）、段落号（如适用）、原文片段
- 满足 ISA 500 审计证据准则的追溯性要求（可被 Reviewer 独立验证）

**产出 Artifact：** `EvidencePackageArtifact`，包含 `claims`、`coverage`（有证据的 claim 比例）、`unmatched`（未找到证据的 claim 列表）。

## Acceptance Criteria

- [ ] `POST /api/v1/evidence/collect` — 输入 `claims: list[str]` + `filters`，返回 `EvidencePackageArtifact`
- [ ] 每条 claim 自动执行 hybrid_search，取 `top_k=10` 候选
- [ ] 支持 `min_relevance_threshold`（CrossEncoder 分数阈值，默认 0.5）：低于阈值的候选被丢弃
- [ ] 去重逻辑：同一 `source_id` + 相同 `chunk_id` 的多条 claim 共享同一 evidence，不重复存储
- [ ] Citation 字段完整：`document_name`、`page_number`（如可提取）、`paragraph_number`（如可提取）、`source_id`、`excerpt`（原文摘录 ≤500 字符）、`source_type`、`retrieved_at`
- [ ] `coverage` 指标准确计算：`matched_claims / total_claims`
- [ ] `unmatched` 列表输出所有未满足 `min_relevance_threshold` 的 claim
- [ ] `GET /api/v1/evidence/{artifact_id}` — 按 ID 获取已生成的 EvidencePackageArtifact
- [ ] OpenTelemetry：`EvidenceCollected` 事件（`evidence_id`、`claim`、`source_summary`）

## I/O Interface

```python
# 请求
class EvidenceCollectRequest(BaseModel):
    claims: list[str]                    # 待验证声明，例如 ["Q4 收入增长 45%", "应收账款周转天数 120 天"]
    filters: SearchFilters               # 复用 2.1.1
    min_relevance_threshold: float = 0.5 # CrossEncoder 最低相关度
    max_evidence_per_claim: int = 5      # 每条 claim 最多保留几条 evidence

# 响应 — EvidencePackageArtifact（来自 Agent Contract v1）
class EvidencePackageArtifact(AuditArtifact):
    artifact_type: Literal["evidence_package"]
    content: EvidencePackageContent

class EvidencePackageContent(BaseModel):
    claims: list[EvidencedClaim]
    coverage: float                      # matched / total
    unmatched: list[str]                 # 无证据的 claim 原文

class EvidencedClaim(BaseModel):
    claim_text: str
    evidence_items: list[EvidenceItem]

class EvidenceItem(BaseModel):
    evidence_id: str
    citation: Citation                   # 见 Agent Contract v1
    relevance_score: float               # CrossEncoder 分数
    source_type: str

class Citation(BaseModel):
    citation_id: str
    document_name: str
    source_id: str
    source_type: str                     # CLIENT_DOCUMENT | AUDIT_STANDARD | WORKPAPER
    excerpt: str                         # 原文摘录，≤500 字符
    page_number: int | None
    paragraph_number: int | None
    chunk_index: int
    retrieval_query: str                 # 用于检索此证据的 query
    retrieved_at: datetime

# API
POST /api/v1/evidence/collect  → EvidencePackageArtifact
GET  /api/v1/evidence/{artifact_id} → EvidencePackageArtifact
```
